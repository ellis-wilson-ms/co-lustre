== Lustre Test Framework ==

|-
|data-sort-value="test-framework"|[http://git.whamcloud.com/fs/lustre-release.git/blob/HEAD:/lustre/tests/test-framework.sh test-framework.sh]
|Provides the fundamental functions needed by tests to create, setup, verify, start, stop, and reformat a Lustre filesystem. 
|}

See the [[TestingLustreCode]] page for details on how to run these test scripts,
and [[Testing HOWTO]] for a worked multi-node setup example.

Test suites are grouped into ''test groups'' under
[http://git.whamcloud.com/fs/lustre-release.git/tree/HEAD:/lustre/tests/test-groups lustre/tests/test-groups].
The <code>regression</code> group defines the suites run against every patch; a
suite's presence in that group is the practical definition of "actively tested".
See [[Test Groups for Patch Testing]] for more detail.

== Lustre Unit, Feature, and Regression Tests ==

{| class="wikitable"
|+Status Key
|-
|<span style="color:green">Active</span>
|Test suite is present in the source tree and is run in AutoTest or has been committed to recently. Suites listed in <code>lustre/tests/test-groups/regression</code> are run for every patch.
|-
|<span style="color:blue">Inactive</span>
|Test suite is still present in the source tree but is not part of a routine test group and has not been committed to recently.
|-
|<span style="color:red">Removed</span>
|Test suite has been deleted from the source tree or replaced by another suite. Retained here so that references in older bug reports, patches, and Maloo results remain interpretable.
|}

'''Note:''' Status reflects the state of the Lustre master branch. To confirm what
exists for a particular release, check <code>lustre/tests/</code> in that branch.
