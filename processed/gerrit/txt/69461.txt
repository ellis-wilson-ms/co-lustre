--- Commit Message ---
LU-20882 scripts: commit-msg avoids leaking temp files

Running the commit-msg hook with --help created its temporary
message file, named from an empty path, in the current
directory and never removed it: a hidden .XXXXXX file with GNU
coreutils, a visible untracked file with uutils.

Create the temporary file only when there is a message to
check, and quote the empty path that --help passes to
basename. Open the input before creating the temporary file
so missing input does not leave a file behind either.
