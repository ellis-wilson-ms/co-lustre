build, docs

Addition of docker files and scripts to build lustre rpm packages
in a docker docker container.
Docker files, with documentation (in markdown), and bash scripts
to build lustre packages in a container.

- Rocky 10.X (experimental for futur lustre 2.18)
- OpenSUSE Leap 15.6 (client)
- OpenSUSE Leap 16.0 (client)
- Ubuntu 24.04 (client)
- Debain 13 (client)

Some concerns, see inline comments. One whole-patch point: when the containers are run the way the shipped Dockerfile comments and readme describe (`docker run --volume ./build:/build ...` from the directory holding the Dockerfile), the script git-clones lustre and writes the whole RPM build tree into `contrib/docker_lustre_builder/*/build/` inside the source tree. Nothing in .gitignore covers that, and `contrib` is listed wholesale in EXTRA_DIST in autoMakefile.am, so a later `make dist` in the same tree would sweep the build output into the tarball. Could the output go somewhere outside the repo, or could .gitignore be extended to cover it?
