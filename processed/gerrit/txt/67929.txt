LU-20581 tests: size the router buffers in test_50

test_50 enabled routing without setting the router buffer
parameters, so LNet allocated the default pool: LNET_NRB_LARGE
1 MiB buffers, about 1 GiB. lnet_nrb_*_calculate() divides by
LNET_CPT_NUMBER and then allocates per CPT, so the total is the
same whatever the CPU count, and a small node cannot spare it.
The import failed with -ENOMEM.

Set small and large to the counts setup_router_test() uses, and
tiny to a flat 16, which is enough because test_50 never routes
traffic. They are read-only parameters, so the test now loads
lnet itself instead of reusing an already configured one.
configure_dlc() takes module options to that end.
