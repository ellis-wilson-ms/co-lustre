LU-20940 dkms: build after DOCA's mlnx-ofa_kernel

Since DOCA 3.2.0, the EL packages ship the OFED kernel modules
as the DKMS module mlnx-ofa_kernel. BUILD_DEPENDS has only the
Debian name mlnx-ofed-kernel, so after a kernel update DKMS may
build Lustre before the OFED modules for that kernel.
