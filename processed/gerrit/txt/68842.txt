--- Commit Message ---
LU-20340 utils: add recursive option to lfs setstripe

'lfs setstripe' can only set a default layout on one directory at a
time; there is no way to apply it to a whole existing tree at once.

Add -r/--recursive: walks the tree via already-opened, O_NOFOLLOW'd
fds rather than re-opened paths, so a symlink can't redirect where a
layout lands, and skips other filesystems mounted below it. A plain
spec is now also built into an llapi_layout and applied the same way
as a composite one, via llapi_layout_set_by_fd().
llapi_file_open_param() is split into fd-based verify/apply helpers
to match.

-r is rejected up front with --component-add/-del/-set, --foreign,
--mirror-count or --restripe. A directory's own failure does not stop
the rest of the tree; the first error is the exit code.
