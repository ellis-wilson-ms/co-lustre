--- Commit Message ---
LU-19794 csdc: use acomp compression API

For kernels 6.15 and beyond use the acomp compression API with DMA
source and destination virtual addresses, instead of the legacy comp
API which was removed there.

The acomp request allocation returns NULL on failure, so the
allocation checks test for NULL and fail with -ENOMEM. The buffers
handed to the request are vm_map_ram() mappings or large pool
allocations, which are not usable for DMA, so they are set with the
non-DMA variants of the request setters.
