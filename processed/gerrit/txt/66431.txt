--- Commit Message ---
LU-16053 osd-zfs: make ZFS 2.0.0 the minimum supported version

... by removing all of the legacy ZFS support from the m4
scripts and the OSD itself.

Per the Lustre Changelog, we have recommended 2.0.0+ since
02-20-2021 (over 5 years). The previous LTS 2.15 recommends
2.0.7. Hence, users can seemlessly update Lustre without
having to update ZFS at the same time.

Apply GPL-2.0 SPDX to the m4 header (the OSD is GPL-2.0, so
the m4 is as well) and update the header.

We remove the SPL configure options. These will be silently
ignored if callers continue to pass them. We retain the
SPL automake and autoconf variable. These will be removed
in future patches.
