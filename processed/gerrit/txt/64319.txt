--- Commit Message ---
LU-19921 ptlrpc: add SEC_CTX_INIT ctx RPC handler

This patch implements server-side termination of the GSSIAM security
context initialization (SEC_CTX_INIT) handshake and connection
context installation, establishing the foundation for cryptographic
token verification in subsequent patches.

Specifically:
- In lustre/ptlrpc/gss/sec_gssiam.c, gssiam_accept() delegates
  context initialization and connect RPCs to gss_svc_accept(),
  which decomposes the security context inside the RPC.
- gssiam_handle_init() handles the SEC_CTX_INIT RPC, creates an
  ephemeral server security context (gss_rsc), generates a 64-bit
  context handle, and replies to the client.
- In lustre/ptlrpc/sec.c and lustre/ptlrpc/service.c, generalize the
  unwrapping check to test req->rq_reqmsg != req->rq_reqbuf instead
  of checking specific security policies. This ensures that embedded
  messages are cleanly unpacked and their swab masks are reset
  across all policies and hybrid framing models, while direct
  null-framed requests preserve their initial unpack state.
- Export lustre_msg_set_cksum() in lustre/ptlrpc/pack_generic.c
  for message integrity operations.
