--- Commit Message ---
LU-0000 quota: ignore edquot if in-fligh request exists

local quota information (including cached edquot) should be ignored
as long as there is in-flight request to acquire quota.
this is to solve a race when just send quota acquisition request
causes local lqe_edquot status update via ldlm glimpse.
