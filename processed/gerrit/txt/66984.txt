--- Commit Message ---
LU-20438 lnet: Implement LNet support for PCI P2P DMA

Modify LNet to handle P2P DMA pages identically to GPU pages,
reusing the existing RDMA-only mechanisms for GPUDirect storage.

Update UAPI and metadata structures to reflect the generalized hardware
design by renaming LNET_MD_GPU_ADDR to LNET_MD_P2PDMA_ADDR and
LNET_MD_FLAG_GPU to LNET_MD_FLAG_P2PDMA. Introduce the lnet_md_is_p2p()
helper to simplify classification across lib-md, lib-move, and pers.

AI code review results below, please doublecheck

Some concerns, see inline comments. The main one is that classifying PCI P2PDMA pages as RDMA-only breaks an invariant the LNDs rely on: before this change lnet_is_rdma_only_page() could only be true when the nvfs/GDS ops were registered, so lnet_rdma_map_sg_attrs() always had a handler. It can now be true with no handler at all, and nothing in the tree yet provides a native p2pdma mapping path. The ni_p2pdma capability bit that would gate this is added but never set or read, so the enabling half and the supporting half of the feature are split across patches in a way that leaves this patch alone incorrect rather than merely incomplete.
