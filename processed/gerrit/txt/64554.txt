LU-19403 llapi: Move nodemap offset functions

Move nodemap_add_offset()/nodemap_del_offset() from obdctl to
liblustreapi, add llapi_nodemap_test.c test14, and add a man3
page for both. cmd_name/nodemap_name become const char *.

jt_nodemap_add_offset()/jt_nodemap_del_offset() now return
EXIT_FAILURE on any library error instead of the raw negative
errno, matching the rest of the series.

llapi_nodemap_add_offset() also rejects limit >= UINT_MAX and
offset + limit >= UINT_MAX, matching checks the server already
enforced but the library was missing; the "not recommended"
warnings move from fprintf(stderr) in obd.c to
llapi_err_noerrno() in the library.
