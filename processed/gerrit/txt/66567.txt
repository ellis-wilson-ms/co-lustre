LU-20212 lov: skip invalid OST mirrors for aggregate I/O

I/O that aggregates stripe-local results into one logical answer
(glimpse, lseek, data_version) cannot succeed on a mirror while
any relevant OST import is deactivated or invalid.

In lov_io_mirror_init(), skip mirrors with inactive OSTs in the
I/O extent during FLR selection for aggregate I/O (glimpse, lseek,
data_version). Only glimpse returns -EAGAIN after mirror-round
backoff so the caller can retry (glimpse is ndely=1); lseek and
data_version fail with -EIO.

For designated-mirror I/O, apply the same extent-scoped inactive
stripe check after resolving ci_designated_mirror; there is no
alternate mirror to try, so return -EIO immediately.

Detect dead stripes with lov_mirror_extent_has_inactive_stripe(),
limited to stripes intersecting the current I/O extent.

Skip parity mirrors for glimpse as well.
Add test sanity-ec 42a,42b.
