LU-20930 lnet: resend batch stop to running nodes

"lst stop" sends the stop once and then polls until no node
reports the batch active. The console does not send the stop
to a node it marked down after one of its RPCs timed out,
such as an "lst stat" sample to a slow node, and a stop RPC
that times out makes "lst stop" return at once. A node that
misses the stop runs all its loops, and "lst stop" keeps
printing "N batch in stopping" until it finishes, which for
the lnet-selftest smoke test can outlast the test session.

Resend the stop every ten polls while nodes still report the
batch running. A query reply marks the node active again, so
the resent stop reaches it. Report a failed stop RPC and
keep waiting rather than return.
