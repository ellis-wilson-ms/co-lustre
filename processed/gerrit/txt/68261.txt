--- Commit Message ---
LU-19744 doc: document the llapi_ioctl(3) return contract

llapi_ioctl(3) said the function returns 0 on success and a negative
value on failure, but it returns the ioctl(2) result directly, so a
failure is -1 with errno set. The one exception is a negative fd,
which returns -EBADF and sets errno to match.
