LU-20338 tcu: non-root user should see and unrm file owned by it

This patch fixes the failure when non-root user access and unrm
files owned by itself.

When create a "pFID" stub object in Trash Can, we also set the
"unrm" XATTR on the object to record the original attributes
(such as UID/GID/PROJID) of the deleting file, so that when unrm
the file, it can obtain the original attributes from the "unrm"
XATTR for the permission check.

Add a new test case sanityn/test_118z to verify the fix.
