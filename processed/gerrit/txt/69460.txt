LU-20882 scripts: fix man page version lookup under dash

checkpatch-man.pl looks up the release that added a man
page's subject by running a git log/awk pipeline through
Perl backticks, which use /bin/sh. The pipeline fed git log
to awk with a bash here-string (<<<). On Debian and Ubuntu
/bin/sh is dash, which rejects that with "Syntax error:
redirection unexpected", so the AVAILABILITY lookup never
ran there and always reported "no git commit hash found".

Pipe the git log output into awk instead, grouped in a
subshell since it can be an "a || b" list, and take the
10-character short hash with substr() rather than another
here-string through head.
