LU-19002 osp: fix debug message in osp_precreate_fids

In osp_precreate_fids(), CDEBUG printed the already-updated *grow
as "Expect", an unused variable i (0) as "actual", and inverted
the start and end FIDs. Fix the CDEBUG output by saving the requested
count in expect beforehand, printing actual *grow, and ordering the
FID range as [start -- end].

Additionally, clean up and align the IDIF handling:
- Clamp the IDIF upper bound to IDIF_MAX_OID - 1 instead of
  IDIF_MAX_OID, so one fewer object per IDIF sequence is handed out.
- Replace the rc check from ostid_set_id() with LASSERTF() since
  the clamped end OID cannot exceed valid bounds.
- Remove the early returns from the IDIF branch so IDIF allocations
  also execute CDEBUG logging and share the common return logic.
- Only update fid via ostid_to_fid() when *grow > 0, so if *grow comes
  out negative or zero, the FID is not moved backwards and the
  function returns 1 (sequence empty) instead of 0.
