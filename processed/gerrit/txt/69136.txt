--- Commit Message ---
LU-14144 utils: remove "lctl modules" command

"lctl modules" printed gdb add-symbol-file commands from a list of
module names and source paths that has not been updated in years,
so it is missing most server modules and names stale .o files.
The kernel's gdb "lx-symbols" script, crash "mod -S", and drgn all
load module symbols properly.

Remove the command rather than keep another list of module names.
Remove the unused "ogdb" symbol dumps from test-framework.sh and
run-llog.sh.  Fix conf-sanity test_25, which passed the bogus .o
paths to rmmod and so never tried to remove any modules.
