LU-19944 tests: skip conf-sanity/11 MGS tools in interop

In conf-sanity.sh test_11, mkfs.lustre and tunefs.lustre are only
available on server installs, so need to be tested on the server.
However, during interop testing the tools version on the MGS will
have a different version and the test will fail.  Also, older tools
may be missing the fix for printing '--version' to work in any case.

Only check the tool versions on the client during interop testing.

Test-Parameters: trivial
Test-Parameters: testlist=conf-sanity env=ONLY=11 serverversion=2.15
