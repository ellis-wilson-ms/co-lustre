--- Commit Message ---
LU-17916 osd: prefer folio of order 0

Switch from struct page and page based API to struct folio
and the folio API while keeping the PAGE_SIZE logic by only
allocating folio(s) of order 0.

Provide lnb_fpgno to track the page number within an lnb_folio
where kmem_to_folio() in osd-zfs can be a large folio.

Propagate lnb_folio to the other osd implementations and
provide lnb_pgno(), lnb_kmap_local(), ll_lnb_kmap_local() and
lnb_folio_page() to manage the lnb_folio and lnb_page consistently.

osd_dio_get_folio in osd-zfs returns -ENOMEM on allocation failure
instead of LASSERT(). -ENOMEM will propagate up the call chain where
  osd_bufs_get() will free allocated memory
  dt_bufs_get() becomes responsible for any further handling.
