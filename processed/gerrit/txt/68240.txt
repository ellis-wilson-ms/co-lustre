--- Commit Message ---
LU-19744 doc: fix the llapi_ioctl(3) example

The example tested an uninitialized rc rather than fd, so a failed
open() went unnoticed, and it handed LL_IOC_GROUP_LOCK a pointer where
the kernel reads the argument as the group id by value.  Use an ioctl
that takes a buffer, and adopt the argc and include conventions of the
neighbouring pages.
