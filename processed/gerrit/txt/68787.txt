LU-10026 lov: pack layout_gen and compr info into lcme

Creating a compressed mirror with "lfs mirror -N" did not produce a
compressed component. Even when the compression parameters were fully
specified, the new mirror was created without compression, and lfs
getstripe showed the mirror entry lacking compression fields.

lov_lsm_pack() did not populate the composite entry fields
lcme_layout_gen and lcme_compr_* when packing a lov_comp_md_v1. As a
result the MDS/client logic took the "no layout/compression in entry"
path and defaulted to an uncompressed layout for the new mirror.
llapi_layout_mirror_inherit() should set compression fields.

Set these fields for each composite entry and set during layout mirror
inherit to fix the problem.

sanity-pfl 100n and 100m were added.
