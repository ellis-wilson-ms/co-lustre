LU-20517 quota: don't grant writes from the leftover grant

When an id reaches its hard limit, the slave may still hold an
unused qunit in lqe_granted.  qsd_acquire_local() checks this
leftover before lqe_edquot, so a write that fits in it succeeds
even though the master has no more space to give. sanity-quota
test_1k fails because of this.

Check edquot flag first: while it is set, return -EDQUOT instead
of using the leftover. Once it is stale, use the leftover again,
same as before (LU-4505). Also release the unused quota grant in
qsd_calc_adjust() as soon as edquot is set, so it does not stay
on the slave.
