--- Commit Message ---
LU-20084 osp: fix LWP namespace cleanup

lwp_device_fini() calls client_obd_cleanup() ->
ldlm_namespace_free_post() without ldlm_namespace_free_prior().
lwp_disconnect() never calls client_disconnect_export(), so
free_prior is never reached on teardown. Without it,
LDLM_NS_STOPPING is not set and nothing waits for ns_bref to drop
to zero. ldlm_pools_count() and ldlm_pools_scan() can still hold
a namespace reference when free_post() frees the namespace, which
is a use-after-free. Call free_prior in lwp_device_fini().

When lustre_lwp_connect() fails, lustre_lwp_setup() returns
before adding the LWP to lsi_lwp_list. Umount only cleans up LWPs
on that list, so the LWP device and its namespace are leaked until
reboot. Clean it up with class_manual_cleanup() on that error.

The lwp_setup() and lwp_init0() error paths still call
client_obd_cleanup() without free_prior. They are left for a
separate change.
