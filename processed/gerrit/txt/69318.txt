--- Commit Message ---
LU-14773 tests: reuse ssh connections for remote commands

Every do_node()/do_nodes() call opens a new ssh connection, paying
TCP setup, key exchange and login, twice with VERBOSE set ("lctl mark"
and then the command). This dominates the runtime of short subtests.

When PDSH uses ssh, share one connection per node (ControlMaster,
ControlPersist=$SSH_MUX_PERSIST, 120s default), with keepalives so a
dead node fails instead of hanging; close it before a node is powered
down or up. The master keeps the cwd it was started from, so ssh runs
via a "cd /" wrapper in $PATH so as not to pin $MOUNT. Run "lctl mark"
in the same call as the command. SSH_MUX=false disables sharing.

sanity subset, 2 servers + 2 clients:  before  after
  VERBOSE=false                          389s   289s
  VERBOSE=true                           473s   269s
