--- Commit Message ---
LU-20855 tests: restore ROOT default LMV in sanity/65n

sanity test_65n saves the default LMV of the root directory by its
stripe count, index and hash type.  The default LMV that the MDT
sets on the root directory has no hash type, so test_65n deletes it
instead of restoring it at exit, and later subtests no longer get
new directories spread over the MDTs by its max-inherit-rr.  Then
sanity test_413d fails with "400 subdirs on MDT0" on a DNE system.

Check for a default LMV by its stripe count, and restore its
max-inherit as well, its max-inherit-rr if it has no fixed MDT index,
and its hash type only if it has one.
