LU-20011 llapi: add flag-based layout sanity API

`lfs mirror split` failed with "Incomplete mirror - must go to
EOF" on a file whose mirror was added to a partial PFL layout.

Introduce llapi_layout_sanity_check() with a bitmask-based
llapi_layout_checks enum to replace the old boolean-parameter
APIs. Deprecate llapi_layout_v2_sanity(), and update callers
(including lfs) to use the new interface; mirror_split() now
passes LLAPI_LAYOUT_CHECK_INCOMP_MIRROR to skip the EOF check
only, the mirror-count check still always runs.
Cover it with a new llapi_layout_test test68.
