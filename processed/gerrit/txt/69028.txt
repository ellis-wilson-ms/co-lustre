LU-20777 lnet: avoid double free for down ip2nets interface

When processing an ip2nets rule, lustre_lnet_match_ip_to_intf()
frees the interface descriptor immediately if the matched interface
is not UP. This can result in a use-after-free and double free during
lnetctl import when an ip2nets rule refers to a down interface.

Leave the descriptor intact when detecting a down interface and let
the existing common failure path report the error and perform the
cleanup once.

Add a sanity-lnet test covering ip2nets import with a down interface.

Test-Parameters: trivial testlist=sanity-lnet
