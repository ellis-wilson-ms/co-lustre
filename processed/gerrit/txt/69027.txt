--- Commit Message ---
LU-18687 build: handle CONFIG_LUSTRE_FS_SERVER tristate

Lustre treats CONFIG_LUSTRE_FS_SERVER as a boolean but when
imported into a Linux kernel it can be a tristate value,
turn off, module, or built in. To properly support
building in the Linux kernel tree with Kbuild using
tristate value we need to use the IS_ENABLED macro.
All other lustre CONFIG_* options are boolean so no need
to update them. For the IS_ENABLED macro to work we need
to define CONFIG_LUSTRE_FS_SERVER_MODULE. We also add
headers that are needed to actually build in the linux
kernel tree.
