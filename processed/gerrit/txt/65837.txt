--- Commit Message ---
LU-20250 build: modernize kernel compat

Use the lustre_compat include model to hide the compatibility
handling needed for older kernel API from the primary code base

Move kthread_use_mm, kthread_unuse_mm, and fault_in_iov_iter_readable
out of primary code and into config.h

Use a bit of trickery to hide compat_bio_alloc so the primary code
only needs to use bio_alloc(). Similar trickery is used for
class_create() so we can easily drop Lustre into a kernel tree.
