--- Commit Message ---
LU-19958 sec: update rev ctx at first req with new flavor

When a security flavor changes, we need to adapt the security context,
and also the reverse context on server side. This can be done only for
the first rq_ctx_init request, but this might not be the first request
received with the new flavor. In this case, we need to delay the
sec context adapt, but the reverse context install must not be delayed
one step further, otherwise we might never get a second chance at
updating it.
