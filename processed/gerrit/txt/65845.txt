--- Commit Message ---
LU-20099 nrs: add minimum bandwidth guarantee for mClock

Add the mClock policy on the classful scheduler. The first tier is the
reservation (R): a minimum rate for each class. A red-black tree sorts
the class buckets by reserved deadline. Later patches add the limit
(L) and weight (W) tiers.

A high priority move can remove a request that no thread served. The
function nrs_mclock_req_del() keeps the class bucket and its deadline
in the tree. The enqueue already charged the bucket for that request.
A second charge puts the class below its reserved rate.

A bulk request with 0 pages now costs one RPC, not 0.

Add sanityn/test_77v{a,b,c,d}. 77j, 77k, 77kc and 77ub also run on
mClock.
