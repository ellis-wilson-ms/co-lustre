--- Commit Message ---
LU-20214 osd-ldiskfs: no support for noacl in 6.0+

Modern kernels don't support noacl mount options (like ext4), since
v6.0-rc4-12-g2d544ec923 ("ext4: remove deprecated noacl/nouser_xattr options"):
1) change test_104a in conf-sanity.sh to use a different option
2) strip noacl if passed to osd-ldiskfs
3) clean up test_104a code style
