LU-20327 tests: clean up after recovery-small 131

test_131 leaves its file behind after client eviction.
Cached size or block count can then differ from server
attributes. test_155 lists the entire test directory across
a client remount, exposing that difference as a test failure.

Remove test_131's file on exit. Have test_155 compare only
files it creates in a directory on MDT0000.

Commit test_155's file creation through the OSD before
setting the replay barrier. The creating client unmounts
before failover and cannot replay that operation. Server
sync does not commit an osd-zfs transaction.

The client attribute consistency defect needs a separate
fix and regression test.

Fixes: 71f8e5d6506f ("LU-14708 ptlrpc: skip unnecessary client eviction")
