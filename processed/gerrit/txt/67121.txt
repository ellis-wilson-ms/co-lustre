LU-19274 contrib: Add spelling check to checkpatch-man

When calling subshell using "qx" the word to check for
spelling was not quoted when passed to hunspell. This
was breaking the shell pipeline. This patch fixes this
by wrapping the word to check in quote.

Before patch
------------
echo <stringh> | hunspell -a -n -p ./rustreapi/.config/lustre.dic
-bash: syntax error near unexpected token `|'

After patch
-----------
echo "<stringh>" | hunspell -a -n -p ./rustreapi/.config/lustre.dic
@(#) International Ispell Version 3.2.06 (but really Hunspell 1.7.0)
& stringh 5 1: string, strings, stringy, string h, striking

This patch also makes spelling dictionary now points to
rustreapi/.config/lustre.dic instead of contrib/scripts/exa.dic
