--- Commit Message ---
LU-20623 llapi: find the parity comp before refusing a delete

llapi_layout_comp_del() and llapi_layout_comp_add_ec() take any
non-zero mirror link id on a data component as a parity component
protecting it.  The link id shares lcme_time_and_id with the
timestamp, which servers wrote only for NOSYNC components before EC
was introduced, so a layout from such a server carries stale bits
there and a plain component cannot be deleted (sanity/27D:
llapi_layout_test test30 and test37 against 2.16 servers).

Look the parity component up by link id and extent before refusing.

Fixes: 22e9e7e8b264 ("LU-12187 llapi: EC layout creation support")
