LU-930 doc: package man pages by directory, not by list

Use wildcards to generate the list pages under Documentation/man*/
instead of requiring that every new manpage explicitly add itself
to the list of files packaged. That is either error-prone and omits
the new page from the package, or causes patches to have needless
conflicts in context, a loss either way.

The man4/ pages gain a new Makefile.am, since they were only added
in this release, and it was deferred exactly to avoid contention.

For man4/ and man8/, wildcards and a short list of filenames are
used to filter out server commands or parameters.  If forgotten, at
worst an extra page is installed on the client.  Checkpatch.pl will
warn on patches changing Makefile.am, since explicit updates should
only be needed rarely when a new server exception is added.

The current explicit list of manpages is left in-place temporarily
for man1, man3, and man8 to avoid conflict with patches already in
flight, but are no longer used for packaging.  They can be removed
in 2.18.53 when older patches need to be refreshed anyway.
