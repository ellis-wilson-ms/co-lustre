--- Commit Message ---
LU-20790 efalnd: Release and refill failed Rx buffers

On the initial Rx handling error paths the buffer is freed but the RQ is
not refilled, which depletes the RQ over time. Refill the RQ on the
error path as well.

In addition, a zero length completion returned without releasing the
buffer at all, leaking it together with its RQ slot. Route that case
through the error path too. Since byte_len is only meaningful for a
successful completion, clear the posted marker as soon as the buffer is
ours and set the received length only after the completion is known to
be good, as both kefalnd_free_rx() and kefalnd_refill_rx() require a
non-negative rx_nob.
