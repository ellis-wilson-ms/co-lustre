--- Commit Message ---
LU-20169 obdclass: duplicate names/units in stats

Change lprocfs_counter_init() and lprocfs_counter_init_units() to
copy the lc_name/lc_units struct fields into lprocfs_counter_header
rather than just referencing the static strings passed at setup.
The name and unit string length are verified at compile time for
inline string literals, and checked at runtime for others.

This is needed since nodemap stats must be available after module
unload (like ofd.ko), so it can refer to names/units provided by a
separate module.

Replace LASSERT() with error return in lprocfs_alloc_md_stats()
since this shouldn't crash the system.

Fixes: a4e54b59911 ("LU-18950 ptlrpc: per-nodemap stats")
