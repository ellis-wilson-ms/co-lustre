LU-18466 mdd: declare layout split before purge

mdd_xattr_split() declares the mirror purge before the layout split
when a mirror is deleted in place (fd == fdv, LU-14521). Declaring
the split bumps the object's layout generation, so the second LOV
declaration on the same object trips lod_save_layout_gen_intrans()
and the whole operation fails with -EINVAL:

  lod_save_layout_gen_intrans() obj ... gen changed from 4 to 5 in
  trans declaration

lfs treats that -EINVAL as "old MDS rejects fd == fdv" and silently
retries through a volatile victim file, so every 'lfs mirror delete',
'lfs mirror split -d', 'lfs migrate -L mdt' and 'lfs pcc delete' has
taken the volatile-file path instead of the purge path since the
generation check was added, printing a stray "cannot get UNLOCK lease
...: Invalid argument (22)" on the way. Declare in the order the
changes are applied, split first, so the recorded generation still
matches.
