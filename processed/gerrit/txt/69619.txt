LU-20118 hsm: return EINVAL when archive ID requires HS_EXISTS

Setting an archive ID without HS_EXISTS exits mdt_hsm_state_set()
with rc still zero from the successful attribute lookup. Return
-EINVAL so the client sees that the request was rejected.

Extend sanity-hsm test 1c to check the return code and verify that
the failed request leaves HSM flags unchanged.

Tested with a rebuilt MDT module on 2.17.59: sanity-hsm/1c passes.
