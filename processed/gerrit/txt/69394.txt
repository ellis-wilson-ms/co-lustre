LU-16495 libcfs: add per-subsystem debug mask overrides

The global debug mask applies the same log levels to every
selected subsystem. Add debug_subsystem.<name> controls so
OSC can log iotrace independently of llite and mdc. Zero
or "default" inherits the global mask; nonzero replaces it
for that subsystem, so "none" leaves only mandatory
messages. A relative "+flag" or "-flag" write to an
inheriting override starts from the global mask. Mandatory
messages and subsystem selection stay unchanged. The files
are generated from the subsystem name list. No file is
created for "undefined", which marks debug markers and code
without a DEBUG_SUBSYSTEM, so it always follows the global
mask.

Update direct mask checks to honor the overrides too. Parse
mask writes into a local copy and publish them with a single
store.

Add man4 pages for debug, subsystem_debug and the new
debug_subsystem.<name> files. Add sanity test_60k to cover
the overrides, next to the other debug-related tests in the
60 series.

A relative write that removes every flag from an override
leaves it at the mandatory classes rather than at 0, so it
does not fall back to inheriting the full global mask.
