LU-17000 lustre: free strings with OBD_FREE_STR()

OBD_FREE(str, strlen(str) + 1) restates the buffer's length at the
free, so the size is right only while it keeps matching the pointer
beside it: llog_osd_open()'s out_name label is reachable with
lgh_name NULL, where it reads as strlen(NULL) + 1.

Use OBD_FREE_STR() instead, which takes the length from the string,
tolerates NULL and clears the pointer, and drop the checks it makes
redundant.  pcc_dataset_rule_fini() loses its assertion on
pmr_conds_str, which fires today when pcc_dataset_rule_init() returns
-ENOMEM before that field is assigned and pcc_dataset_add() then
cleans up.  Sizes not measured from the string at the free, and LNet,
which has no LIBCFS_FREE_STR(), are left alone.
