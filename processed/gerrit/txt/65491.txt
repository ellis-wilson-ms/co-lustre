--- Commit Message ---
LU-18041 lustre: canonicalize IPv6 NID-derived UUIDs

A UUID holds 39 characters. A full-width IPv6 NID has 43 or more, so
the MGC setup fails with -EINVAL, and the mount fails.

Keep the NID string as the UUID when it fits, so no working UUID
changes. Otherwise, use the 16 address bytes in hex and the '@net'.
If that form does not fit, drop bytes from the start of the address.
Both UUID producers use nid_is_nid6() and accept only UUID_MAX.

lustre_add_mgc_failnodes() now skips a NID that does not fit. A group
with no usable NID no longer ends the list. The old code also wrote
the rejected NID into the group UUID.
Add conf-sanity test_158 for a wide failover NID.
