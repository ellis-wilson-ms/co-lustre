LU-20565 tests: lower required OSTCOUNT for sanity-ec/7d

The FLR layout for the test file in sanity-ec/7d currently requires 8
OSTs. The OSTCOUNT check, however, only checks for 6. Patch testing
for sanity-ec runs in a configuration where 8 OSTs are available. In
full (full-part-3) testing for master and master-next, it is run with
7 OSTs causing the file create to fail on mirror creation with ENOSPC.

For test 7d such a complex layout is not needed since it is only about
the number of mirrors. Therefore, reduce the OST requirements of the
test, so that 7d can run in environments with fewer OSTs.
