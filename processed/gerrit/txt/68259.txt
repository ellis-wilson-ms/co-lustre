--- Commit Message ---
LU-20559 lod: bound the lod_get_ea() retry for real

lod_get_ea() bounds its retry with LASSERT(count++ < 10), so with
--disable-libcfs-assert the counter never advances and the retry
after a racing LOVEA shrink is unbounded.

Make the bound real C. This changes the return contract: eleven
consecutive shrinks used to LBUG() the MDS and now return -EAGAIN,
which lod_striping_load() passes through to mdd_xattr_set(),
mdd_layout_change() and mdd_migrate_object(), all of which already
restart on it. The kernel doc is corrected to match what the
function has always returned on success, a positive EA size.
