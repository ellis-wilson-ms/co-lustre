--- Commit Message ---
DRAFT LU-20244 tests: add tests for resync of FLR + EC

We can have files that use FLR mirroring but at the same time also use
EC to protect the FLR mirrors.
It is probably not common to use as a persistent end user configuration
as Mirrorins and EC usually are meant for different purposes :
with Mirroring being prefered when performance outweights storage cost
and EC is preferred when storage costs outweigh performance.

But there will be situations where FLR+EC will be in use during a
transitionary period, for example when migrating an EC protected file
between different storage hierarchies.

As such we need to have a test for this situation and that we can
support and resync buth FLR and EC components at the same time.
