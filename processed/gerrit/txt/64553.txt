LU-19403 llapi: Move nodemap modify function

Move nodemap_modify() from obdctl to liblustreapi as
llapi_nodemap_modify(), taking the property name directly instead
of a separate enum lcfg_command_type that could disagree with it;
the property -> LCFG_NODEMAP_* mapping moves into the library too.

Add llapi_nodemap_get_offset(), filling in a new
struct llapi_nodemap_offset_info (lnoi_-prefixed uid/gid/projid
fields) instead of returning a single int, replacing obd.c's
duplicate lcfg_get_nm_offset_limit(). Man3 pages are added for
both functions.

The offset-range warning moves to llapi_err_noerrno(), fixing a
spurious ": Success (0)" suffix, in both the library and
jt_nodemap_add_idmap().
