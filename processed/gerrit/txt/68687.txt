--- Commit Message ---
LU-20706 osp: don't resend failed layout version updates

OSP shouldn't try to resend failed layout version updates (-EINVAL):
such an update has no chance given layout version never goes back.

sanity-flr produces few cases like this, so it should be enough to
ensure the code is tested.
