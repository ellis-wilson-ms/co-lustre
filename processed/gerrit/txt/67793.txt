--- Commit Message ---
LU-20557 llog: don't call llog_size() if rc is set

The llog_cat_size_cb() calls llog_cat_process_common()
which leaves NULL llog_handle on negative rc. However
there is missing check for rc == 0 before the call to
llog_size(), leading to a NULL llog_handle usage.

As a result, reading mdd.*.changelog_size might cause
an Oops in llog_size() in negative rc code path.

Patch adds explicit check that rc is 0 prior llog_size()
call.
