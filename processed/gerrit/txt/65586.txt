--- Commit Message ---
LU-20178 tests: add compression test suite

Add sanity-compr.sh test suite for CSDC with 109 test
cases covering:

- Basic write/read with each compression algorithm
  (lz4fast, lz4hc, lzo) and all supported chunk sizes
- Compression ratio validation ensuring compressed
  data is smaller than uncompressed for compressible
  content
- Incompressible data handling (random data stored
  uncompressed)
- Mixed I/O patterns: sequential, strided, append,
  partial-chunk, sub-chunk overwrites
- Truncate and hole punch on compressed files
- mmap, O_DIRECT fallback, and sendfile integration
- Multi-component layouts with compression on
  selected components
- Sparse file handling and extent verification
- Concurrent multi-client stress tests
- Data integrity stress with compressible,
  incompressible, and mixed data patterns
