LU-20869 tests: shorten sanity-pfl test_8 dbench run

sanity-pfl test_8 ran dbench for its default 600s plus a
120s warmup, about 12 minutes. The dbench loadfile writes
no file larger than 1.9MB, so with the 2M/16M/EOF layout
only the first component was ever instantiated however
long dbench ran.

Run dbench for 60s and shrink the component extents to
256K/1M/EOF so the larger dbench files instantiate all
three components.

sanity-pfl test_8 in a single-node VM: 722s before, 74s
after.
