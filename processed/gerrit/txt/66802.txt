--- Commit Message ---
LU-20419 build: Make --enable-modules work correctly

If explicit "--enable-modules" is given as input to
configure, it still leaves HAVE_NATIVE_LINUX_CLIENT
defined. The behavior of default action and
"--enable-modules" should be same. It should not define
HAVE_NATIVE_LINUX_CLIENT. Only --disable-modules should
define HAVE_NATIVE_LINUX_CLIENT

Also, improve configure --help message for --disable-modules

Before patch
=============
./configure --enable-modules
...
cat config.log | grep NATIVE
define HAVE_NATIVE_LINUX_CLIENT 1
...

After patch
=============
./configure --enable-modules
...
cat config.log | grep NATIVE | wc -l
0
