LU-20603 llapi: add llapi_scan_namespace()

Add llapi_scan_namespace(). It walks a mounted filesystem and gives
the caller one record per object, instead of a formatted line.

The parameter block and the record can grow:
- lfsp_size is how much of the parameter block the caller knows.
  Unknown bytes must be zero, up to 4096 bytes.
- lfsp_want selects the fields to fetch. lfsp_got says which ones
  the scan can answer.
- lfsr_valid says which fields were filled.
- Unknown lfsp_flags bits are refused.

The record starts with a struct statx, followed by the Lustre fields.

Shared helpers fixed on the way:
- The callers with no FID clear the record up to lmd_lmm before
  conversion, so no stale FID, stx_mask or lmd_lmmsize is left.
- llapi_scan_get_lmv() clears lum_pool_name and does not touch a
  foreign directory's LMV.
- get_projid() is no longer static. Its per-object messages are
  LLAPI_MSG_DEBUG.

llapi_scan_namespace.3 documents the API, including how long each
part of a record stays valid.

Test: new llapi_scan_test, run by sanity test_157c.
