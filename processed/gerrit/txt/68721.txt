LU-20714 llite: reject NUL byte in foreign symlink path

A foreign symlink destination path is built by copying the foreign
LOV/LMV EA value, which any user can set, into the resolved path
buffer. An embedded NUL byte is not rejected there, and readlink()
and path lookup treat that buffer as a C string, so the link resolves
to a truncated, wrong destination, and ll_foreign_put_link() then
frees strlen(cookie) + 1 instead of the allocated size.

Reject a NUL byte in the built path in both parse methods, which also
makes the strlen() derived free size exact, and add sanity test 27Pc.
No in-tree producer of a foreign EA or upcall item emits one.

Also drop a stale XXX: on a foreign inode lfm_type was checked when
the symlink ops were installed, and lfm_length is bounded by the
cached EA this buffer was packed from.
