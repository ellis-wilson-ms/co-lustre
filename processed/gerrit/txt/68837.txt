LU-20723 tests: run review groups with a single client

Most review test groups do not use the second client node. This patch
runs each of the proposed single-client review groups with
clientcount=1 on the usual 2-MDS/4-MDT/1-OSS layout to confirm that
the suites pass without a second client VM, so that Autotest can stop
reserving one for them.

conf-sanity test_127 called zconf_umount_clients with an empty
$RCLIENTS list, which shifted the arguments and tried to run the
umount on a node named after the mount point. Guard the call so the
test is a no-op for remote clients when there are none.

Test-Parameters: fortestonly
Test-Parameters: clientcount=1 mdscount=2 mdtcount=4 osscount=1 ostcount=8 testlist=sanity
