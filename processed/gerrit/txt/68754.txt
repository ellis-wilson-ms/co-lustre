LU-20583 llite: move statahead generation to lli_sax_intall

statahead generation is used to prevent redundant cache lookups.
The generation global counter is incremented inside lli_sai_alloc().
The current lli_sa_generation is copied in dentries when they first
access the statahead cache. If dentry and inode generation match in
dentry_may_statahead() statahead thread will not restarted.

This check is not valid for shared pattern. Several thread are started
for the same inode, for each thread generation is incremented. So the
lli generation will match only with the last thread.

Replace global sai_generation with atomic sax_generation and move
generation counter initialization to ll_sax_install().
