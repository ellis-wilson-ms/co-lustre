--- Commit Message ---
LU-17000 utils: set errno when llapi_ioctl() rejects a bad fd

llapi_ioctl() short-circuits a negative descriptor with -EBADF but
leaves errno untouched, so its callers' "rc = -errno" idiom turns the
failure into success whenever errno happens to be zero.  Set errno on
that path, as the documented return contract already promises and as
the sibling l_ioctl() helper already does.
