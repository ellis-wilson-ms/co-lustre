LU-20037 mdc: allow error on write to mdt on CL_FSYNC_DISCARD

mdc_io_fsync_start() should not return error running for
CL_FSYNC_DISCARD so that cl_io_start() did not break its loop over
slices. Otherwise, ll_truncate_inode_pages_final() finds undiscarded
pages and fails with: (osc_page.c:182:osc_page_delete()) Trying to
teardown failed: -16.

Test to illustrate the issue is added (sanity.sh:test_907b).

sanity.sh:test_907 is renamed to test_907a and changed to use one
write(2). Using several writes made it possible for intentionally
failed write rpc to happen before unlink which breaks the test.  Also,
at the end of test call to multiop is added so that the test survives
ONLY_REPEAT set to > 1.
hybrid_io is disabled to avoid switching to direct I/O.
