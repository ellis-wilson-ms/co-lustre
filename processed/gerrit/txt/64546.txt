LU-19403 llapi: Add new exists nodemap function

llapi_nodemap_exists()'s 0-means-exists/1-means-missing return
convention is easy to misuse.

Add llapi_nodemap_check_exists(), a bool-returning replacement.
llapi_nodemap_exists() is kept under a version guard and marked
deprecated, so out-of-tree callers keep building for two more
releases before losing the symbol.

Convert the lctl nodemap_new/nodemap_del call sites in obd.c to
the new function and add llapi_nodemap_test.c test8/test9.
jt_nodemap_del() also gains the same llapi_name_verify() check
jt_nodemap_new() already had, rejecting an invalid name before
any lookup.
