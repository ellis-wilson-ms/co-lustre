LU-20499 tests: set facet vars for auster -N

setup_if_needed() skips setup under the -N flag without calling
init_facets_vars, so mdsN_svc/ostN_svc/mgs_svc stay unset.
convert_facet2label() then fails with "No label for mds1!" for any
test that looks up a service label, when auster is pointed at a
filesystem that is already up.

Fix: when -N is given and the target filesystem is already mounted,
call init_facets_vars before returning, in both setup_if_needed()
and do_check_and_setup_lustre(). Do not call it when the filesystem
is not mounted, since -N is also used by lower-level tests (e.g.
OBD device loading) that intentionally run against
unformatted/unreachable devices, where init_facet_vars's label
lookup would otherwise retry for up to 19s and then exit(1). Use an
explicit "return 0" so the not-mounted case (where is_mounted fails)
does not leak a nonzero status out of these functions.

Fixes: 0439aaadb1b6 ("LU-16936 auster: add --client-only option")
