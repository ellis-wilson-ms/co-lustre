LU-14058 tests: clean up sanity.sh MDT name generation

Many sanity.sh tests and test-framework.sh helpers open-code the MDT
name as $FSNAME-MDT000x, so they break with more than 10 MDTs.

Use the ${MDT[]} array, which get_lustre_env() now populates for
every suite, or mdtname_from_index(), which now generates the name
from FSNAME so it works before the filesystem is mounted.  Fix the
pool helpers to process all MDTs, using the pool's own filesystem
name since conf-sanity/32h runs them on a separate filesystem.

Fix tests that assumed few MDTs: test_33h/33hh, 51f, 160i, 230o/p/q
and 413a/b/c.  Except test_51d, 160h, 181 and 300ug with many MDTs
until they are fixed.

Also fix mountmds() to pass $mdsnum to switch_identity(), so that
IDENTITY_UPCALL is actually applied at mount time.  Version checks
in modified subtests now use the landed commit, so test_33hh skips
2.15.x servers that do not have crush2.

Test-Parameters: testlist=sanity mdscount=6 mdtcount=24
