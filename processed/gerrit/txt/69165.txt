LU-20818 clio: copy only smaller unaligned DIO reads in chunks

WIP, not for landing: the default below is bracketed by two
measurements rather than pinned by one, and the harness those
came from is being recalibrated.

A read split into many sub-DIOs already copies them in
parallel, one thread per completing sub-DIO.  Splitting each of
those into chunks as well puts more threads on the copy than
memory can feed.  On a file striped over 16 targets with 4MiB
stripes, so one sub-DIO per 4MiB, a 256MiB read lost 18% with
1MiB chunks, while 4MiB and 64MiB reads gained 50% and 15%.

Record the size of the IO on its cl_dio_aio, clamped to what a
read can actually cover, and chunk a read's copy only while the
sub-DIO count is below obdclass dio_read_copy_max_subdios;
beyond it each sub-DIO is copied in one thread as before.

The default of 32 sits in the band the measurements bracket,
which gained at 16 sub-DIOs and lost at 64.

The count assumes the sub-DIOs are submitted in parallel, which
llite.*.parallel_dio=0 turns off; that setting is a debugging
aid on a long stable feature, so it is not accounted for.
