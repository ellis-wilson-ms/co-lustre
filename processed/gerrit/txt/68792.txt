LU-10026 tests: FID retrieval from getstripe

Some tests rely on the getstripe output to obtain
an object's FID. However, for compressed files, the
getstripe output format differs significantly.

This patch introduces a function that handles both
output formats. All functions potentially affected
by this change have been updated accordingly.
