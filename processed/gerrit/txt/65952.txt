--- Commit Message ---
LU-17920 tests: improve checkpatch.pl return checks

The checkpatch.pl return code check, USE_NEGATIVE_ERRNO warning
only triggers on the most basic "return EPOS" error code, not
for "(rc|ret|retval|err) = EPOS; return rc;" or "ERR_PTR(EPOS)".

Fix the USE_NEGATIVE_ERRNO check to detect and report those cases.

False positives were hit in the MGC llog and PtlRPC connect handling.
Add comments when setting and checking to explain this is intentional.
