--- Commit Message ---
LU-10026 utils: return error on invalid compress level setting

lfs setstripe -Z <compress_type>:<compress_level> does not report
error on invalid <compress_level>.
An explicit low level for the lz4 type (below the lz4hc minimum) is
no longer silently rewritten to the lz4fast default at parse time;
the stored level is kept and the compression engine falls back to
lz4fast for such levels when allocating the compressor.
