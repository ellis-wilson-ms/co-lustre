LU-12668 ec: add --stats and -W into EC resync

lfs mirror resync already parsed --stats/--stats-interval and -W
and passed them to llapi_ec_resync_many_params(), but the EC
parity path ignored both. Large EC-only resyncs then produced no
progress output, so users and lamigo (which uses the periodic
YAML lines as a liveness heartbeat) saw a silent process.

Introduce llapi_resync_progress_account() to thread the existing
FLR stats/bandwidth helpers through parity read, write, punch, and
zero-fill, and add sanity-ec 12g/12h.

- Example,
$ $LFS mirror resync --stats --stats-interval=1 -W 1M $tf
- { seconds: 4, rmbps:     3, wmbps:     1, copied: 4, total: 16, pct: 25% }
- { seconds: 8, rmbps:     2, wmbps:     1, copied: 16, total: 16, pct: 100% }
