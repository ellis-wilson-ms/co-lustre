LU-18231 obd: change obd_need_scrub into OBDF_NEED_SCRUB

Change the use of the obd_need_scrub bitfield into a bit in
the obd_flags bitmap and use atomic bit set/clear/test
operations on it. Place this field at a new offset in the
enum so we have room for any potential new client bit
fields being added in the future.

No logical changes to the code and no changes to locking.
