LU-20720 osd: xattrs from the otable iterator

An object's FID and attributes do not say whether it has a layout,
what its SOM size is, or what it is named; its xattrs do.

DORA_XATTR asks the iterator for a named xattr while it still holds
the object.  On ldiskfs an inline xattr is in the inode-table block
the iterator has, so the common case costs no read; an external
block is read when it must be.  On ZFS the bonus buffer answers the
same way.  osd_otable_it_xattr() is the per-backend entry point.

DORA_STATS reserves counters for how those reads divide between the
tiers, since whether the common case really is free is the number
this rests on.
