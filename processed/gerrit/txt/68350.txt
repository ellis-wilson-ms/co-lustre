LU-10026 tests: memory check depends on RAM

Each open file consumes about 4.7KB of RAM, 300000
files consume about 1.3GB. At systems with 2.6GB RAM
it might cause an OOM with SLOW=yes option.
1. Consume 40% of RAM to check that page pools would be
shrinked.
2. Change createmany with memhog.
3. Export MEMHOG in init_test_env.
