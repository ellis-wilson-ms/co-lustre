The change has no test coverage, and the existing LU-11926 regression test can no longer catch this class of bug. sanity test_319 was reworked in abe5c93175 to run `lfs migrate -m1` on the parent directory, but ll_migrate() only takes a lease for S_ISREG children, so no lease lock is created at all; on top of that the racing `dd if=$file` is a read open (LCK_CR), which is compatible with the LCK_PW lease and never produces a blocking AST.
