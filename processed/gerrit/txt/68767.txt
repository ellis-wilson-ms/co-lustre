LU-17000 lnet: fix use-after-free in lnet_add_net_common()

lnet_startup_lndnet() consumes the net it is given: on success it
either links it into the_lnet.ln_nets or, when its NIs were merged
into an already existing net, frees it.  lnet_add_net_common()
looks the live net up again by id for that reason, but the
lnet_ping_target_setup() failure branch runs before that lookup
and hands the stale pointer to lnet_shutdown_lndnet().  Adding an
interface to an existing net, e.g. "lnetctl net add --net tcp --if
eth1" while tcp is up, faults there when the ping buffer cannot be
allocated.

Set the ping buffer up after the lookup, so that no error path can
reach the consumed pointer.
