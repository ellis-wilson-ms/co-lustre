LU-20846 llite: close the open handle on PCC open failure

ll_file_open() releases lli_och_mutex before pcc_file_open() and
then sends a pcc_file_open() failure to out_och_free, whose cleanup
belongs to the locked section.  On that path the mutex is released a
second time, and the och that ll_local_open() already filled with
the MDS open handle is freed without an MDS_CLOSE, so the MDT keeps
the file open until the client is evicted.  When the och is shared
with other open file descriptors, they are left pointing at freed
memory.

Undo the local open with ll_md_close(), as file release does, and
return through out_nofiledata.

A PCC-RO attached file whose cache backend is read-only fails its
O_RDWR open with -EROFS from dentry_open(); add sanity-pcc test_49
to check that the MDT holds no open handle after such an open.
