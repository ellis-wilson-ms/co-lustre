LU-20611 llapi: split cb_find_init's decider out

Move the second half of cb_find_init() into find_decide(). It takes a
struct find_ctx instead of the walk's local variables, so a caller
that has a record but no path can use the same checks. Fields that the
caller does not have are NULL or -1.

The project id lookup moves into find_get_projid(). A walk opens the
object and asks the ioctl. A record that already has a project id uses
it. A caller with nothing to open gets -ENOTSUP. No caller in this
patch does that; the device scan later in the series does.

The split itself changes no behaviour. Compared line by line with the
old function, the only edits are:
- "goto decided;" became "return 0;"
- "goto out;" became "return ret;"
- some declarations moved into cb_find_init()
- the project id 0 is written as DEFAULT_PROJID (also 0), in the code
  and in one comment
- "goto print;" became "goto run_decide;", a new label in
  cb_find_init()
- the fp_get_lmv/fp_check_foreign block moved out of the
  "if (want != 0)" body to the top of find_decide(). It now also runs
  when want == 0 and on the find_foreign_accepts() arm, and comes out
  the same either way:
  fp_get_lmv stays 0 unless scan_rec_gather_begin() ran, and
  lfsr_valid gains LLAPI_SCAN_LMV only in scan_rec_gather_finish(),
  which that arm skips

find_decide() returns 0 or a negative errno. It does not report
whether the object matched, because no caller uses that.

Two small fixes to LU-20605 ("llapi: build find on the scan record")
are carried here, so that patch can land unchanged. The first changes
what -printf prints; the second is documentation:
- -printf %Lc, %Lh, %Li and %Lo print nothing for a directory off
  Lustre, instead of a stub's 0 or "none", as for a file.
- scan_rec_gather_finish() documents its own rules: it fetches for
  any @want, and the caller closes the fd it opens.

-printf also prints an unknown %L letter, or a trailing %L, as it
stands for an object off Lustre, as it does on Lustre. Before, a
trailing %L on a file with no layout made printf_format_string()
read past the end of the format string.
