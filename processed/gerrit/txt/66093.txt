--- Commit Message ---
LU-16915 tests: show correct os-release file

On Ubuntu 24.04 and later there is no /etc/system-release file,
only /etc/os-release, so it prints "file not found" on each load.
The lustre_os_release() function already used only this file, so
set a variable to use same file consistently, and only print it
out in case of error.  It already prints system IDs on success.
