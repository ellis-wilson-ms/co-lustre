LU-19921 ptlrpc: Test the fix and getting some debug

This patch is just to test the fix and get the debug message
from the environment, not for real landing.

Add a warning message in upcall_cache_flush when an entry is skipped
because its reference count is non-zero. This helps diagnose cases
where modules cannot be unloaded because resources are held.

Also add a temporary sleep in test cleanup to verify if garbage
collection delay is causing module unload failures.

This is for testing purpose only.
