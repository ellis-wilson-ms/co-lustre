LU-19946 utils: add --mmp option to mkfs.lustre

Add a new --mmp command-line option to mkfs.lustre to enable
the MMP (Multiple Mount Protection) feature when formatting
regardless of failover configuration. Add --nommp as the
preferred spelling of the existing --skipmmp option, which is
kept as an alias. --mmp is rejected with an error on ZFS
targets, since MMP is an ldiskfs-only feature.

tunefs.lustre also gains --mmp and --nommp, allowing MMP to be
added to, or removed from, an existing ldiskfs target.

Drop the is_e2fsprogs_feature_supp("-O mmp") probe and
disp_old_e2fsprogs_msg(), since MMP support has been present
in e2fsprogs long enough that the fallback message is no
longer useful.

## Summary

**What the fix was:**

I removed the unused `disp_old_e2fsprogs_msg()` function, including both its forward declaration (line 81) and its complete definition (lines 466-492).

**Rationale:**

The applied patch modified the MMP (Multiple Mount Protection) feature implementation in the `enable_default_ext4_features()` function. The original code had a conditional check to see if e2fsprogs supported the MMP feature:

```c
if (is_e2fsprogs_feature_supp("-O mmp"))
    append_unique(anchor, ",", "mmp", NULL, maxbuflen);
else
    disp_old_e2fsprogs_msg("mmp", 1);
```

The patch simplified this to unconditionally enable MMP (lines 610-614 in the patched version):

```c
if ((mop->mo_flags & MO_FAILOVER) && !(mop->mo_flags & MO_NOMMP)) {
    append_unique(anchor, ",", "mmp", NULL, maxbuflen);
}
if (mop->mo_enable_mmp)
    append_unique(anchor, ",", "mmp", NULL, maxbuflen);
```

This removed the last remaining usage of `disp_old_e2fsprogs_msg()`, which was a helper function to warn users when their e2fsprogs version was too old to support certain features. Since the function was no longer called anywhere in the code, the compiler correctly flagged it as unused, causing a compilation error when `-Werror` (treat warnings as errors) was enabled.

The fix removes the dead code, which is the appropriate solution since the patch assumes MMP support is always available in the current e2fsprogs versions being used.
