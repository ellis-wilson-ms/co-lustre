--- Commit Message ---
LU-17000 llite: reject an empty FID array in ll_rmfid()

LL_IOC_RMFID with fa_nr == 0 allocates a zero-length rcs[] array and,
because lfa->fa_nr is then also 0, evaluates rcs[nr - 1] before the RPC
is sent.  nr is unsigned, so the index is UINT_MAX and the read lands
far outside the allocation, oopsing the client.

lfs rmfid never submits an empty batch, so refuse it in the ioctl.
