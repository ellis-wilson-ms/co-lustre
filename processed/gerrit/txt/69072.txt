LU-18687 compat: fix kallsyms_lookup_name() function cast

On kernels that export kallsyms_lookup_name(), such as some
vendor 6.6 kernels, the build fails with:

  lustre_compat/symbols.c: In function 'find_kallsyms_lookup_name':
  error: cast between incompatible function types from
  'long unsigned int (*)(const char *)' to
  'void * (*)(const char *)' [-Werror=cast-function-type]

kallsyms_lookup_name() returns unsigned long, not void *. Store
the pointer with its native prototype, so no function type cast
is needed, and convert the returned address to void * in
cfs_kallsyms_lookup_name(). This also avoids calling the function
through a mismatched type, which would trap under kCFI.
