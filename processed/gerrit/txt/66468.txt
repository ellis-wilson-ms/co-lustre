LU-16974 tests: run sanity/56xi+56xl even if no yaml

Avoid skipping sanity.sh test_56xi and test_56xl entirely when YAML
file parsing is not installed.  That only affects a small part of
these subtests, and the YAML check can be run at the end if present.

Also fix verify_yaml() calls in test_56bb and test_56bc that were
incorrectly checking the filename rather than the file contents.
