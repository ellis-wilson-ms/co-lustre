LU-20741 lfs: add --remote option to lfs find

Add two new features to lfs find:
- --remote: filter files and directories that are not on the same
  MDT as their parent directory.
- New printf formats:
  - %LR: print the MDT index of the parent directory.
  - %Lm: print the MDT index of the file or directory.

These options let users identify files and directories that have an
agent inode. Agent inodes are needed to record on which MDT an object
is stored, but they are not visible through the filesystem. This
causes a mismatch between the usage users see in their quota and the
number of files they can find with lfs find.

With --remote, users can identify these objects and better understand
the discrepancy.

Also fix an indentation issue in the lfs-find manpage.
