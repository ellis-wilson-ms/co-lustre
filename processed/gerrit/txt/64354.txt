--- Commit Message ---
LU-19947 quota: dump transaction info in error path

When we exceed QUOTA_MAX_TRANSIDS, Lustre will print an error
message. But we should dump more info about the quota
transaction so we can better root cause the issue. Otherwise,
it's not obvious if we are facing a legitimate bug.

Record the FID of the object being modified in lquota_id_info
so that the dump shows which objects were involved, alongside
the quota type, ID, block/inode flag and space for each ID
already in the transaction and for the ID which did not fit.
The OSD layer has no knowledge of the operation type, but the
FIDs together with the space changes should be enough to
identify the operation in most cases.
