--- Commit Message ---
LU-18461 layout: batch a join operation

A join moved a single file into its target, so an S3
CompleteMultipartUpload had to issue one RPC per part and the
resulting file was built one layout at a time.

Let a join name any number of files: 'lfs join <target> <part>...'
and llapi_join_layouts_multi() pass the whole list, the MDT locks
the target and every part, moves the layouts in at the offsets the
client computed and removes the emptied parts.  A batch is validated
as a whole, so a part which cannot be joined rejects the request
before any layout is moved.
