LU-15856 utils: 'lfs mkdir -D LAYOUT DIR' creates DIR

It is now possible to use 'lfs mkdir -D LAYOUT DIR' to create a
new directory with the specified layout and then set the default
layout on the new directory in a single command.  Previously this
needed 'lfs mkdir LAYOUT DIR' to create the directory and then a
separate 'lfs setdirstripe -D LAYOUT DIR' command to set the
default directory layout.  'lfs setdirstripe -D' and 'lfs mkdir -d'
still fail if DIR does not exist.

Reject '-D -i x,y' up front, since the default LMV never supported
a list of MDTs, and the old hint to add '-c' only led to EINVAL.

Also fix the sanity test_413e version check for LU-13440.

Test-Parameters: trivial
Test-Parameters: mdscount=2 mdtcount=4 testlist=sanity env=ONLY=413e
