LU-20806 osd-ldiskfs: check fake file setup for failure

Setting up a fake file can fail with -ENOMEM since it gained an
LSM blob.  Two callers, the LMV check and object sync, went on
to use the error pointer as a file.  Return the error instead,
as the other callers do.
