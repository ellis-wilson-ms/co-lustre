--- Commit Message ---
LU-20107 nrs: add per-rule statistics to the class scheduler

The rule dump shows only the configured rate. An administrator cannot
see the rate that a rule gets.

Add counters to each rule: enqueue, dispatch, exhausted, a dispatch
count for each mClock tree, and the reset time. The dispatch counter
counts bytes for a BPS limit and RPCs for an IOPS limit.

Add the entry nrs_<policy>_rule_yaml, which prints the rules and their
counters in YAML. The command "lctl get_param --yaml" reads that entry
when it exists. The write "reset_stat [rule]" to the rule entry clears
the counters.
