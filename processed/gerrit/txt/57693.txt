## Summary

**The Fix:**
Added `#include <ctype.h>` for userspace builds to provide the `isalnum()` function.

**Rationale:**
The patch moved `nodemap_name_is_valid()` from a kernel-only file (`lustre/ptlrpc/nodemap_handler.c`) to a shared header file (`include/uapi/linux/lustre/lustre_disk.h`) that is included by both kernel and userspace code. 

The function uses `isalnum()` to validate nodemap names. This function comes from different header files depending on the context:
- **Kernel space**: `<linux/ctype.h>` (already added by the patch)
- **Userspace**: `<ctype.h>` (was missing, causing the compile error)

The fix adds an `#else` branch to include `<ctype.h>` when building for userspace (`#ifndef __KERNEL__`), ensuring that `isalnum()` is available in both contexts.
