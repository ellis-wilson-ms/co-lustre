LU-18813 osd-wbcfs: enable sanity/51b

Define an approximate size per inode so we can re-enable
test sanity/51b. Use the same conservative 4KB estimate
as ldiskfs: the inode itself is ~1KB, but there is other
overhead to take into account.

Remove reference to sanity/0f, which does not exist.

Test-Parameters: testlist=sanity fstype=wbcfs mdscount=4 mdtcount=1 osscount=4 ostcount=1
Test-Parameters: testlist=sanity fstype=wbcfs combinedmdsmgs=false standalonemgs=true mdscount=1 mdtcount=1 osscount=4 ostcount=1
