--- Commit Message ---
LU-20528 utils: Make several options work in lfs quota

1) lfs quota marked --all, --default-usr, --user, --group and
   --projid as required_argument so each of them wrongly consumed
   the following argument. For example, lfs quota --user 1000
   /mnt/lustre failed with invalid id '/mnt/lustre'.
2) d: is missing from the getopt_long() optstring, so lfs quota -d
   is rejected as an unrecognized option.

Also drop the argument from the -U/-G/-P descriptions in OPTIONS,
and add -d to the 'lfs quota' usage and the SYNOPSIS.
