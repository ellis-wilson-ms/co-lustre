--- Commit Message ---
LU-20950 lnet: reject fault commands before LNet is up

Load the lnet module. Before "lnetctl lnet configure", run any
"lnetctl fault" add or del command. The node oopses in
lnet_drop_rule_add() or lnet_delay_rule_del(). The oopsed thread
holds delay_dd.dd_mutex, so unconfigure then hangs.

The netlink handler lnet_fault_cmd() calls the rule functions
directly. Only LNetNIInit() initializes the rule list heads. The
ioctl path calls LNetNIInit() first, so it does not oops.

Take ln_api_mutex in lnet_fault_cmd() and return -ENETDOWN when
ln_refcount is 0. This matches the other netlink handlers. Add
sanity-lnet test 637 to run each fault command before configure.
