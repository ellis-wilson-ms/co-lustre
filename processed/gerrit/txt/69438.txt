--- Commit Message ---
LU-20546 osc: check request pack rc with "if (rc)"

ptlrpc_request_pack() clears rq_import on error. Some callers
check its result with "if (rc < 0)", so Coverity cannot see that
the request is never sent after a failed pack:

  CID 506496: FORWARD_NULL in osc_punch_send()

The pack never returns a positive rc, so this is a false positive.
Use "if (rc)" like the other callers, to silence it.
