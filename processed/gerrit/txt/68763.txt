--- Commit Message ---
LU-20724 tests: add fsx burst mode for multiple mounts

With multiple paths to the file, -I rotate switches path
every operation and -I random picks a path per operation.
Neither dwells on one mountpoint.

Add -I burst[:maxops]: do 1 to maxops (default 16)
operations on one path before switching to a different
one.  The burst is counted per operation, so an operation
that touches a path gets its size check on that path.

Arm the first burst after the setup calls in main(), which
reach get_tf() themselves: that picks the starting path
uniformly, including path 0, and clears the fd_burst_used
they leave behind.

Add sanityn test_16m to exercise it over two mounts.
