LU-9827 mdt: check open sequencer during migration

to migrate a file from one MDS to another, the client is given
a lease lock in PW mode which is to notify client upon concurrent
open operation.  then the client passes lock's handle to MDT to
do actual migration. this way ldlm lock on the child is taken
before ldlm lock on the directory stripes - which is a violation
of regular lock ordering.  a concurrent operation (like open)
taking locks in the regular order can lead to a deadlock.

this is a prototype to verify the idea: introduce open sequencer
which increments every open, then check the sequencer hasn't changed
since lease lock is released, otherwise interrupt migration.
