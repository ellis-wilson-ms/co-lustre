--- Commit Message ---
LU-19616 ldiskfs: return error if journal start fails

In the base ext4-projid-xattrs.patch, ext4_xattr_set() handling of
the "trusted.inodefl" xattr only stored the error from a failed
ext4_journal_start() and then fell through, passing the ERR_PTR
handle to ext4_mark_inode_dirty() and ext4_journal_stop(). Return
PTR_ERR(handle) immediately instead, matching the linux-5.14
variant of the patch.

Fixes: 78cb85212c0d ("LU-19616 ldiskfs: keep inode flags after migration")
