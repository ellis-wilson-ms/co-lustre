--- Commit Message ---
LU-18400 tests: enable spl_panic_halt

Set spl_panic_halt when loading osd-zfs and when creating or
importing zpools, so SPL assertion failures panic the node and
leave a crash dump instead of hanging the offending thread. Old
SPL versions without the parameter are silently skipped.
