--- Commit Message ---
LU-20861 build: support ->create() without excl argument

Linux commit v7.2-rc1-9-gb2f1e6301efa ("Remove excl arg to ->create
inode_operation") dropped the bool excl argument from
inode_operations.create(), so ll_create_nd() and memfs_create_nd() no
longer match the ops table type on v7.3.

Add a configure check for the four-argument form. Define
ll_create_nd() and memfs_create_nd() with that signature and adapt
their declarations for older kernels through lustre_compat/linux/fs.h,
including kernels without the namespace argument.

Remove excl from the ll_create_nd() debug message; neither callback
uses it for create semantics.
