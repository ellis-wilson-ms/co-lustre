LU-20770 dbg: disable socklnd zero-copy for 2.16 interop test

Debug-only: raise the default zc_min_payload above the maximum
payload, which is what LU-12945 did on hypervisors until LU-19763
(bf67df32127, landed 2026-01-28) removed that guard.  The
lustre-master interop matrix against 2.15/2.16 servers passed on
build 4695 (2026-01-15) and hangs on every bulk write from build
4697 (2026-01-29) on, on VM clients; if this passes where the
baseline times out, the zero-copy send path on VMs is the trigger.
