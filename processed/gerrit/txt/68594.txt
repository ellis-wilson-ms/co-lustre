LU-20099 nrs: add nodemap classification to class scheduler

LU-17902 added the nodemap classification type to the TBF policy.
The classful scheduler abstraction predates that change. It has no
nodemap field. It has no nodemap type flag. It has no nodemap key
member.

The rebase of this series onto master therefore removes nodemap
support from the TBF policy.

Add the nodemap type to the class scheduler. The scheduler then
gives the behavior that LU-17902 gives.

- Add NRS_FIELD_NODEMAP and NRS_TYPE_FLAG_NODEMAP.
- Add struct nrs_nodemap and the nk_nmid key member.
- Add the nodemap entry to the class type table.
- Add the nodemap list parse, match and free paths.
- Set and mask nk_nmid in the key routines.

Squash this commit into "abstract rule-based classful NRS scheduler"
after the author agrees. The nodemap feature is then present at
every commit of the series.
