--- Commit Message ---
LU-17000 quota: fix error pointer put in qmt_reset_slv_cb()

smatch reports 'slv_obj' as "an error pointer or valid" in
qmt_reset_slv_cb().  slv_obj comes from dt_locate(), and its failure
jumps to the exit path with the error pointer still in the variable, but
the exit path only tests it against NULL before calling dt_object_put().
Any dt_locate() failure on the slave index object therefore dereferences
an error pointer while resetting a quota ID.  qmt_dqacq0() spells the
same test "slv_obj != NULL && !IS_ERR(slv_obj)"; use IS_ERR_OR_NULL()
here.
