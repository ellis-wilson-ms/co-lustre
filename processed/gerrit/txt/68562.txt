--- Commit Message ---
LU-20679 lfsck: do not process OBD_IDX_READ too long

Processing of OBD_IDX_READ may be long. Allow the lfsck orphan
iterator to stop on getting close to the rpc deadline and return to a
caller even if nothing was saved into the containers. The caller then
continues the iteration.

Test to illustrate the issue is added. It is considered failed if
OBD_IDX_READ rpc times out (the test sets at_max to 20 to shorten the
test run-time) or if not all layouts are recovered by lfsck.

sanity-lfsck test_45 is changed to use wait_all_targets_blocked
waiting for lfsck completion, so that test_46 does not start while
lfsck from the previous test is still running.
