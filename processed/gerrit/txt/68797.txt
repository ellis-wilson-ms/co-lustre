--- Commit Message ---
LU-10026 ofd: properly locate root object

ofd_init0() gets root object by using dt_locate_at() with
an OSD device as top. As result lu_object can be incomplete
if it doesn't exist yet. Instead dt_locate() should be used.

Patch fixes that and adds error handling in related places.
When the compr_stats file cannot be obtained the reference is
cleared, so that it is neither saved nor released at fini.
