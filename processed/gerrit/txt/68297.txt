--- Commit Message ---
LU-20596 tests: discover peer after the NI add

setup_health_test() discovers the remote peer before it adds a second
NI to that peer. The local peer record then holds one NI.

lnet_health_check() sets attempt_remote_resend to false when the peer
holds one NI. LNet then does not resend the message after a remote
failure. The first remote_* ping of test_233 fails with -EIO and no
resend.

Discover the peer again after the code adds the NIs. Check that the
local peer record holds all remote NIs. Only the multi-rail path adds
NIs, so keep the single-rail tests on their previous path. Clean up
the remote NI when a check fails, because the test exits in a subshell
and cleanup_health_test() does not run again.
