LU-20070 kernel: add rhel10.2 server support

Add four ldiskfs patches and a series file for RHEL 10.2 (kernel 6.12):
ext4-add-fstrim-mount-option, ext4-add-periodic-superblock-update.patch,
ext4-dirdata-lustre-compat, and ext4-mballoc-for-hybrid.

Add the x86_64 server kernel config for RHEL 10.2
(6.12.0-211.40.1.el10_2), and register the 6.12-rhel10.2.series
patch series in which_patch and ChangeLog.
