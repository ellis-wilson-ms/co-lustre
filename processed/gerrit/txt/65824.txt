--- Commit Message ---
LU-20234 build: fix -Werror=discarded-qualifiers errors in utils

Fix assignments where strchr/strstr/memchr return values (typed as
char *) were assigned to char * variables whose input was const char *,
causing the compiler to flag discarded const qualifiers.

For read-only uses, change local variables to const char *. For
llog_process_records and its callbacks, change the record parameter
to char * since the function genuinely modifies the buffer in-place
and callers should not be surprised when data is modified. For
print_quota, cast the strstr result to char * before null-terminating
through the const pointer.
