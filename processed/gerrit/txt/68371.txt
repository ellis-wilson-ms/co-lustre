This patch is the first of two patches that add counters
to track client/server-side data compression statistics.
This patch add new compr_stats file in osc.*.compr_stats.

From added counters:

   client to compressed files, in chunk/bytes;

csdc: rename client-side stats

Some CSDC client-side stats can be confusing for the uninitiated:
- write_pages_compr is the number of pages from the 'raw' file that
  could actually be compressed;
- write_pages_uncompr is the number of pages from the 'raw' file that
  count not be compressed;
- write_chunks_compr is the number of chunks from the 'raw' file that
  could actually be compressed;
- write_chunks_no_compr is the number of chunks from the 'raw' file
  that count not be compressed;
- read_pages_compr is the number of pages from the 'raw' file that
  were actually compressed;
- read_chunks_compr is the number of chunks from the 'raw' file that
  were actually compressed;

So rename those parameters as follows:

    write_pages_compr -> write_pages_compressible
    write_pages_uncompr -> write_pages_incompressible
    write_chunks_compr -> write_chunks_compressible
    write_chunks_no_compr -> write_chunks_incompressible
    read_pages_compr -> read_pages_compressed
    read_chunks_compr -> read_chunks_compressed

And also change the corresponding field names in struct client_obd to
make them more explicit.
