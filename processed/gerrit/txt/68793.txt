--- Commit Message ---
LU-10026 tests: enable CSDC layout in sanity-compr.sh

Enable CSDC layout on root mount in sanity-compr.sh and run the
sanity and sanityn suites with that layout. Subtests that do not
work with a compressed root layout yet are excepted when the layout
carries a compression component, and a few tests are adjusted to
either disable compression for the file under test or to account
for compressed data (block usage, statistics, FID parsing).

sanity test_127a skips its sum check only when the layout is
compressed, and sanityn test_93 reads the OST index from both the
plain and the composite getstripe output.
