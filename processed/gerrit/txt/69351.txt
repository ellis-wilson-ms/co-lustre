LU-20860 doc: add AGENTS.md and skills for AI agents

AI coding agents used for Lustre development have no shared
guidance, so each one learns the process, coding style and test
conventions separately, often from stale wiki pages.

Add AGENTS.md with the rules every agent session needs, skills in
.agents/skills (also visible as .claude/skills) for the patch
workflow, coding style, test scripts and commit messages, and a map
of the code in Documentation/internals.md.  Point to the ltvm and
llm_code_and_review_tools projects for test VMs and for the Gerrit,
Jira and CI tools rather than repeating their instructions.

Also update the commit hooks, checkpatch hints and other files in
the tree that disagree with this guidance.
