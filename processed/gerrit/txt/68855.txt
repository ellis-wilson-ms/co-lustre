LU-20107 nrs: lend the idle ceiling share of a global rule

A global rule divides its rate over the CPU partitions. LNet binds a
NID to one partition, so a client with one NID gets only one share.
The rule then wastes the shares of the idle partitions.

Add a token pool to the node class of a global rule. The pool gets the
node rate over time, less the cost of each dispatch. When a partition
is over its ceiling, the pool can pay for the request. The request
then goes out at once. The pool holds at most one bucket depth for
each partition. It lends only the ceiling share.

The YAML rule dump adds pool_tokens and pool_draws. Add
sanityn/test_77xg. It needs 2 CPU partitions.
