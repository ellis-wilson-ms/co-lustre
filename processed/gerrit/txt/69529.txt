--- Commit Message ---
LU-19916 idl: reserve OBD_CONNECT2_MGS_TYPE flag

Reserve OBD_CONNECT2_MGS_TYPE at 0x40000000000000ULL for an MGC that
treats mgs_nidtbl_entry::mne_type as a mask, so the MGS can mark a
target whose node also runs an MGS follower.  Only the flag,
obd_connect_names[] and the wire checks are added here so the value
can land before the feature patch.
