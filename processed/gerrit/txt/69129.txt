--- Commit Message ---
LU-20798 libcfs: ensure GFP_NOFS is set with vzalloc_node()

Since vzalloc_node() do not currently allow to specify a
memory allocation mask of GFP flags, this is required to
prevent dead-lock situations when memory reclaim code
could re-enter Lustre code.
