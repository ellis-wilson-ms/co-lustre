--- Commit Message ---
LU-18687 build: sync header location

For the Linux kernel normally headers are included with
<linux/*.h>. Lets handle it the same way as Linux kernel
proper for our internal LNet headers. This will help with
downloading the Linux kernel Lustre version to build.
To do this move the LNet headers to include/linux/lnet.
Also move the lustre user land only headers from the kernel
source tree to the top level.
