LU-18917 tcu: implement per-user subdirectories in Trash Can

Implement per-user subdirectories in Trash Can to separate user
files. The directory name should be the UID of the inode being
deleted, not the UID of the process doing the deletion.

Add test case sanityn/117d to verify it works as expected.
