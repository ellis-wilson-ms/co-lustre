--- Commit Message ---
LU-20264 llite: allow idmapped mounts

When a filesystem sets FS_ALLOW_IDMAP, the VFS passes a mnt_idmap
[1] to filesystem operations so users and groups in a user
namespace can be mapped to real users and groups on the host. Now
that the previous patches thread struct mnt_idmap through the llite
create/setattr/getattr/xattr paths, the mdc wire packers and the
ptlrpc request, mark the lustre filesystem type FS_ALLOW_IDMAP so
mounts with a non-trivial idmap report the correct uid/gid in MDS
and OST RPCs instead of the calling task's raw fsuid/fsgid.

[1] https://www.kernel.org/doc/html/latest/filesystems/idmappings.html
