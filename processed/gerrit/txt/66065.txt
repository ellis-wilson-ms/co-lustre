--- Commit Message ---
LU-20292 build: improve kernel rpm naming for RHEL

Improve Lustre kernel rpm naming for RHEL to include the same version
as the baseline kernel.
On RHEL 9 and 10, rely on the kabiversion contained in the kernel
spec file, and on RHEL 8 use the pkgrelease. This is necessary in
order to get the full kernel version that includes the distro variant
like .el8_10 for RHEL 8.10.
