LU-19403 llapi: Move nodemap new and del functions

Move nodemap_new()/nodemap_del() from obdctl to liblustreapi as
llapi_nodemap_new()/llapi_nodemap_del(), so they can be reused
outside lctl. cmd_name/nodemap_name/parent_nm become const char *.

The library functions now validate cmd_name/nodemap_name and
existence themselves (-EEXIST/-ENOENT) instead of leaving it to
the caller, so jt_nodemap_new()/jt_nodemap_del() in obd.c no
longer duplicate these checks and instead derive their error
messages from the library's return code.

Add Documentation/man3/llapi_nodemap_new.3 (llapi_nodemap_del()
redirects to it).
