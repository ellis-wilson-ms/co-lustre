LU-20305 tcu: allow deleting subdirs under a striped dir

In mdd_trash_topobj_set(), for remote parent, we should still use
the existing logic to locate the correct MDT trash directory,
if LMV xattr is present, because the LMV hash chooses the parent
stripe FID owns the dirent independently of the child's home MDT
selected by "lfs mkdir -i".
Also, sanityn.sh test_118v is added to verify this fix.
