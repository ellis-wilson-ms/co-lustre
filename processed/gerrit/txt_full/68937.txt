LU-20760 lnet: forward ko2iblnd module options

The ko2iblnd install helper dropped command-line module options, so
test_310 could not set its timeout.
Pass $CMDLINE_OPTS to ko2iblnd-probe as arguments and forward them
to modprobe using "$@".
