LU-20536 lwp: export import state

Export LWP connection import stats the same way
as OSC or MDC do: connect_flags, server_uuid,
timeouts, import and state.

The LWP setup is reordered so client_obd_setup()
(which initializes obd->u.cli) runs before the
debugfs files are created, otherwise these
import-dependent files could be read before
u.cli.cl_sem/cl_import exist.

OSP and LWP are linked into the same osp module and
export the identical import-stats files. Instead of
each defining its own copy of the file_operations,
add LDEBUGFS_SEQ_FOPS_R[OW]_TYPE_SHARED() variants
that emit non-static fops and an
LDEBUGFS_SEQ_FOPS_TYPE_DECLARE() helper to declare
them. lproc_osp.c now defines the osp_*_fops once and
lwp_dev.c reuses them, removing the duplicated LWP
copies.
