LU-0000 debug: validate max_pages_per_rpc bulk MD workaround

Add sanity test_119t. It drives the same full-size unaligned O_DIRECT
write as test_119s but caps the client at osc.*.max_pages_per_rpc=240,
the field mitigation, and requires the write to complete with no
oversize bulk-match drop. On an unfixed build test_119s reproduces the
MD-count mismatch while test_119t passes, so the workaround holds. On
a fixed build both pass.

Refactor the shared setup and reproduction into a bulk_md_pack_write()
helper so both tests exercise an identical geometry and differ only in
the client RPC-size cap.
