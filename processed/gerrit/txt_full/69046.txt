LU-20107 nrs: add a virtual clock fail_loc for scheduler tests

The scheduler tests measure rates with timed I/O. They take about 4600
s on Maloo, and VM noise lets some checks pass on broken code.

OBD_FAIL_PTLRPC_NRS_VCLOCK (0x538) gives the schedulers a virtual
clock. Each dispatch adds cfs_fail_val ns, and a throttle moves the
clock to its deadline. A cfs_fail_val of 0 holds each dispatch outside
the force mode. A cfs_fail_err above 0 sets a dispatch budget.
OBD_FAIL_PTLRPC_NRS_NPARTS (0x539) divides a global rule rate by
cfs_fail_val partitions.

The tests now queue an exact backlog and check dispatch counts. Add
the rule statistics "forced" and "clock_wait". The virtual clock does
not test real timers, real pool accrual, load, or races. Short timed
tests keep that coverage.
