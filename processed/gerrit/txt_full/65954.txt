--- Commit Message ---
LU-00000 lov: fix "lov tgt 0 not cleaned!" error on unmount

Debug log show that this is false positive triggered
by wrong error checking in lov_cleanup().

- The error condition checks tgt->ltd_active instead of actual
  reference count. A target may be active (ltd_active=1) but still
  have zero references (ltd_refcount=0)

- Function calls getref() which is not requied

Reproducer on Rocky 10 client
-----------------------------
$ llmount.sh
$ umount /mnt/lustre

logs (after fix)
----------------
(lov_obd.c:768:lov_cleanup()) lov_cleanup: refcount BEFORE getref = 0, deathrow = 0
(lov_obd.c:599:lov_del_target()) uuid: lustre-OST0000_UUID idx: 0 gen: 1 exp: ffff8b5e010cb400 active: 1
(lov_obd.c:804:lov_cleanup()) lov_cleanup: refcount AFTER getref = 0
