LU-18687 llite: cleanup BDI_CAP_* flags

According to git commit v5.9-rc3-156-ged7b6b4f6e91 upstream
we don't need BDI_CAP_CGROUP_WRITEBACK anymore for SB_I_CGROUPWB
to function. For older kernels we need to keep it around. Also
SB_I_CGROUPWB has been around since 4.1 so we don't need the ifdef
anymore for SB_I_CGROUPWB.

For git commit 2841808f35eebfd07150333f3af3007cb2904a09 upstream
BDI_CAP_WRITEBACK_ACCT was removed. This is only needed for
wb_stat_mod() handling which is not used by lustre and also was
removed upstream. We can remove the wb_stats handling as well.
By default the Linux kernel enables a similar type of accounting
with newer kernels.

Due to these changes we can greatly simplify Lustre.
