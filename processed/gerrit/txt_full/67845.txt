--- Commit Message ---
LU-20253 tests: check inode size after tiny writes

Add sanity test_23e to verify that a write taking the tiny write
path (ll_do_tiny_write()) updates the inode size. A first sub-page
write dirties the page through the normal write path, then a second
sub-page write to the same page takes the tiny write path and
extends the file.

statx with AT_STATX_DONT_SYNC ($STATX --cached=always) reports
i_size_read() without triggering a glimpse, exposing the stale size
that in-kernel i_size_read() users (like overlayfs) would observe.

Test-Parameters: trivial testlist=sanity env=ONLY=23e
