LU-17238 obd: Introduce mdt_body field mbo_xattr_absent

Repurpose mbo_padding_9 in struct mdt_body as mbo_xattr_absent and
define MBO_XA_* bitmask values for individual xattr names. The field
will be used as a bitmask indicating which system xattrs were looked
up and confirmed absent on the inode during replies.

This will be used to populate the negative xattr cache feature added
in a following commit. The first implementation will prepack system
xattrs during lookup intent reply, to save on extra RPC round trip for
SELinux, but mbo_xattr_absent could be used in any metadata RPC to
pack on negative xattr information as needed.

By using a bitmask, the server can communicate negative xattrs with
very low overhead and without committing to adding an xattr list to
operations like lookup. It also has the flexibility to support up to
64 different system xattrs should future needs arise.
