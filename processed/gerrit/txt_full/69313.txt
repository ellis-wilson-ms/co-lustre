LU-20790 efalnd: Free Rx buffer on lnet_parse error

lnet_parse() can return an error and in that case LNet doesn't call the
LND receive callback, which means the Rx buffer is never released and is
leaked together with its RQ slot.

Return the lnet_parse() return code, so that handle Rx flow will release
the buffer on error. LNet only returns a negative value before taking
ownership of the buffer, so there is no risk of releasing a buffer that
LNet owns.
