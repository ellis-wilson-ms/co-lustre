LU-20568 lfs: allow --ec 1+1

--ec required k >= 2, so a component with one data stripe could not
be protected. Allow k == 1. That parity is a copy of the data stripe,
which is 1+1 on the current layout: one parity object in the same
extent.

Userspace also accepts p > 1 when k == 1, for example --ec 1+2, and
copies the data onto each parity object. The kernel changes that store
this 1+N parity without outgrowing a finite extent are follow-up
patches. For k >= 2, p <= k is unchanged.
