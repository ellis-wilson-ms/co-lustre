--- Commit Message ---
LU-20090 nrs: add a rule sequence number for rule order

A rank change moves a rule in the list, but a cached class bucket
keeps its old rule. The new order never reaches the traffic.

Give each rule a sequence number. A newer rule has a larger number and
a higher priority. An insert or a rank change renumbers the list. The
rule dump shows the number in a "seq" field.

The dynamic hash lookup keeps the bucket whose rule has the largest
sequence. It trims the key to the type of that rule. When the trimmed
key names a live bucket, the lookup refreshes the rule of that bucket.

Add sanityn/test_77t{e,g,i}.
