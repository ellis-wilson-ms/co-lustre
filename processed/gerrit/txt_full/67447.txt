LU-20435 tests: skip sanity/430a for older clients

The sanity.sh test_430a behavior was modified to avoid ZFS blocksize
expansion during testing now that the DMU SEEK_HOLE/SEEK_DATA feature
is working properly.  However, older clients can detect the new server
has seek_hole support and will run the old version of this test, which
fails because ZFS blocksize expansion confuses the test, not because
ZFS seek support is broken.

Skip test_430a for older clients without the modified seek hole test.
This will skip both ldiskfs and ZFS OSTs, but only for a short window.
The current remote exception mechanism doesn't allow checking FSTYPE.

Merge sanity.56aa.ex into sanity.ex now the merge conflict is gone.
This reduces the number of files that need to be processed each time.
