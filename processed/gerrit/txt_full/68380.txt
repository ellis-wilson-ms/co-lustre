LU-10026 csdc: exponential backoff of incompressiblity check

If a file is incompressible and after a round of compressibility
check, if it remains incompressible, this patch would doubles the
skip bytes before running into another round of compressiblity
check.

This patch adds a state machine for update_compression_info(), the
states could be CS_INCOMPR, CS_COMPR, CS_CHECK, CS_CHECK_INC.

CS_INCOMPR    --  file is not compressible
CS_COMPR      --  file is  compressible
CS_CHECK      --  was in CS_COMPR, is now under check phase
CS_CHECK_INC  --  was in CS_INCOMPR, is now under check phase

state transition:
INCOMPR --> INCOMPR   : skip bytes has not been passed
INCOMPR --> CHECK_INC : skip bytes has been reached, in check phase
COMPR   --> CHECK     : in check phase, checked bytes has not been
                        reached
CHECK*  --> CHECK*    : in check phase, checked bytes has not been
                        reached
CHECK*/COMPR
          --> COMPR   : file is determined to be compressible
CHECK/COMPR
          --> INCOMPR : file is determined to be incompressible, reset
                        the skip bytes check length
CHECK_INC --> INCOMPR : file is determined to be incompressible,
                        double the skip bytes check length

====

Test with 4 OSTs system, target file layout is set as:
lfs setstripe -Eeof -c-1 -Z lz4 --compress-chunk=64 $tf

and src file is 336M bz2 file, using "dd if=$src of=$tf bs=4M" copy
this bz2 file to target file.

w/o the patch, copy uses about 7 seconds

** end 1724216095 **
...7 seconds

w/ the patch, copy uses about 4 seconds

** end 1724215241 **
...4 seconds
