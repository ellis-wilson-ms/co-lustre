LU-19946 utils: add --mmp option to mkfs.lustre

Add a new --mmp command-line option to mkfs.lustre to enable
the MMP (Multiple Mount Protection) feature when formatting
regardless of failover configuration. Add --nommp as the
preferred spelling of the existing --skipmmp option, which is
kept as an alias. --mmp is rejected with an error on ZFS
targets, since MMP is an ldiskfs-only feature.

tunefs.lustre also gains --mmp and --nommp, allowing MMP to be
added to, or removed from, an existing ldiskfs target.

Drop the is_e2fsprogs_feature_supp("-O mmp") probe and
disp_old_e2fsprogs_msg(), since MMP support has been present
in e2fsprogs long enough that the fallback message is no
longer useful.
