LU-19430 llite: set FMODE_CAN_ODIRECT on open

Since Linux v6.10 ext4 no longer sets ->a_ops->direct_IO, marking DIO
support via FMODE_CAN_ODIRECT in ext4_file_open() instead. While a PCC
cached file is mmapped, its mapping carries the PCC backend ->a_ops,
so do_dentry_open() sees no DIO support and rejects O_DIRECT opens,
breaking llapi_pcc_detach_file() and sanity-pcc tests 6,7b etc. Set
FMODE_CAN_ODIRECT for regular files in ll_file_open(), since Lustre
implements O_DIRECT itself.
