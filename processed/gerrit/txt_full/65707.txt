--- Commit Message ---
LU-20227 lod,llite: fix div-by-zero on uninitialized os_bsize

When a snapshot MDT is mounted in DNE configuration, lod_foreach_mdt
iterates sub-MDT OSPs. If a sub-MDT OSP returns rc=0 with uninitialized
opd_statfs cache (os_bsize=0), lod_statfs_sum() silently shifts
sfs->os_bsize down to zero, which eventually causes a divide-by-zero
kernel panic in ll_statfs_project() when project quota is active.

Server side (lod_dev.c):
Add the same os_bsize==0 guard in lod_foreach_mdt that already exists
in lod_foreach_ost to prevent this silent corruption.

Client side (llite_lib.c):
Add a defensive f_bsize==0 check in ll_statfs_project() before the
division, falling back to 4096, to prevent kernel
panic even if a corrupted os_bsize=0 reaches the client.
