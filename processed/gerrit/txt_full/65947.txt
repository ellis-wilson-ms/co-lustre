--- Commit Message ---
LU-20099 nrs: set and output the reserved/limit rates

Add reserved and limit rate keys to the rules of TBF and mClock:

    resvd_rate  resvd_iops  resvd_bps    reserved rate
    limit_rate  limit_iops  limit_bps    limit rate

The reserved rate cannot be above the limit rate. TBF holds only a
reserved rate. Until the mClock limit tree exists, the plain "rate",
"iops" and "bps" keys set the reserved rate. An mClock rule no longer
takes "realtime=".

Each class head records in nh_conf_flag the keys that its policy
accepts. Any other key returns -EINVAL. A change command writes only
the rate that its key names, and only when the ceiling check passes.
The ceiling check compares the rates. A change command does not take
realtime=. The mClock rule dump prints a byte rate that is not a whole
MiB/s in B/s.

Add sanityn/test_77ve. Extend sanityn/test_77uc.
