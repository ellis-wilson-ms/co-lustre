--- Commit Message ---
LU-20076 tests: avoid extra remote commands in log()

log() marks the message in the debug log of every node with
do_nodes(), which with VERBOSE first sends another "lctl mark" for
that command, so every log() costs two round trips to all nodes.

When log() runs from rpc.sh on a node that do_rpc_nodes() reached,
it also starts a new pdsh from that node to all nodes, so an rpc to
N nodes makes N^2 connections.  This is hit by wait_import_state(),
wait_recovery_complete(), load_modules() and others.

Call do_nodes() with --quiet from log(), and in RPC_MODE only mark
the local debug log.  Export RPC_MODE in rpc.sh instead of setting it
only for the init_test_env call, since a caller's RPC_MODE=false is
inherited when do_rpc_nodes() runs on the local node.

Average time on 3 nodes (MDS, OSS, client) over ssh:

                               before  after
  log() with VERBOSE           0.43s   0.23s  (-47%)
  do_rpc_nodes to 2 servers    0.55s   0.33s  (-40%)
