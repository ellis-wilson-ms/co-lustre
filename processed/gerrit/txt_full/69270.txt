LU-14058 tests: fix multi-target test script issues

mount_facet() only waits for a new target to register with the MGS
when the label matches ':[a-zA-Z]{3}[0-9]{4}', which never matches a
hex index such as OST000a or MDT000f.  Such targets are not waited
for, and ${facet}_svc may be set from the unregistered label, like
"lustre:OST000a", breaking later facet_svc users on that facet.

Match hex digits in the target index.  Also replace the ':', '=' or
'+' in an unregistered, writeconf or no-local-logs label when setting
the facet service name, so it matches the registered name.

Also fix sanity/802c to set the OSTs readonly on all OSS nodes, not
only on ost1, and sanity/803b to read md_stats from the mds facet
that serves each MDT, instead of mds0 for MDT0000 and so on.
