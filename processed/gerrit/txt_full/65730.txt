LU-20099 nrs: abstract rule-based classful NRS scheduler

Move the rule-based classful scheduler out of the TBF policy into
nrs_class.c and lustre_nrs_class.h, so that mClock can use it. The TBF
class bucket becomes struct nrs_tbf_class. struct nrs_class_ops holds
the policy callbacks. The class code keeps the nodemap classification
type.

Four ptlrpc module parameters get new names. Each old name stays as a
deprecated alias:

    tbf_jobid_cache_size -> nrs_class_cache_size
    tbf_rate             -> nrs_class_def_rate
    tbf_depth            -> nrs_class_def_depth
    tbf_dyn_rule_thresh  -> nrs_class_dyn_rule_thresh
