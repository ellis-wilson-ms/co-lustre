LU-20107 nrs: enforce node-wide TBF limits with shared tokens

Each CPT runs an independent NRS scheduler, making it difficult to
enforce an aggregate IOPS or bandwidth limit across a server node.
Dividing the rate statically among CPTs also leaves capacity unused
when requests are distributed unevenly.

Implement node-wide token accounting for global TBF rules under HSCH.
Attach the same reference-counted node class to the corresponding
per-CPT rules, allowing active CPTs to draw from a shared quota rather
than a fixed per-CPT allocation.

Add struct nrs_node_token, one for each rate slot of the node class,
under nrs_node_class::nnc_tok_lock. Each rule holds its node class in
nrs_rule::nr_node_cls. The TBF path calls nrs_node_token_consume() to
take a node token. A class bucket that holds a node token sets
NRS_CLASS_TOKENIZE_BIT.

Account for RPCs and pages within a sliding window, pacing token
grants with shared deadlines. Shift a bounded surplus or debt into
the next window and reset accounting after an idle period. When quota
is exhausted, stagger token retries through the per-CPT throttle
timers. A retry stays inside the next window. A class bucket that
the node class refused asks again only after its retry deadline.
A rate change keeps the node token that a class bucket holds, so
the node window does not count that token twice.

A BPS rate with no IOPS part counts pages only. Its RPC rate is only
the cost of a request with no pages, so it is not a quota. A request
with no pages costs the pages of 1 MiB, as on the CPT tier.

Update TBF enqueue and dequeue paths to reserve node tokens and honor
their deadlines while retaining the existing behavior for non-global
rules. Keep separate limit and reservation token states for future
mClock integration, and document the shared-token design.

Add sanityn tests 77we and 77wf using direct fio reads of sparse files
to exercise single-client and aggregate multi-client rate limiting
without allocating bulk OST data. Cover idle-window restart, returning
to a single active client, and stopping a rule during I/O. Test 77we
also checks a bps= rule with reads of one page.
