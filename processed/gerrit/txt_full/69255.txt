LU-20808 lod: add a raw xattr accessor

An MDT answering a lock intent for a peer returns parent xattrs for
the peer to put in its OSP object cache, where they have to be the
same bytes an OUT_XATTR_GET would have returned. Reading them through
moo_xattr_get() does not give that for a directory: LOD's
do_xattr_get() loads the shards of trusted.lmv, rewrites LOV_MAGIC_SEL
and synthesises the root default layout.

Add do_xattr_get_raw / dt_xattr_get_raw() and moo_xattr_get_raw /
mo_xattr_get_raw(), which return the value as stored. LOD implements
it by reading the device below it. A device that does not interpret
the value needs nothing, as dt_xattr_get_raw() falls back to
do_xattr_get().
