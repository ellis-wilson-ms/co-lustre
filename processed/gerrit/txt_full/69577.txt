LU-19323 lnet: return legacy node ids from lst console

The console keeps a struct lnet_processid for each node,
but copies it to the ioctl reply by size as the legacy
struct lnet_process_id. lstcon_rpc_trans_interpreter()
fills struct lstcon_rpc_ent's rpe_peer this way, and
lstcon_nodes_getent() fills struct lstcon_node_ent's
nde_id. Batch, stat and error replies get the first bytes
of the large NID, and the node list copies more than the
legacy field holds. lst then prints node ids such as
"0-200@<30:61450>", so a failure cannot name the node.

Convert the id to the legacy struct before copying it out,
with a shared lstcon_id2id4() helper in console.h so the
two paths cannot drift apart. Reject ids that do not fit
instead of truncating the address.
