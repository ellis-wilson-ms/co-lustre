--- Commit Message ---
LU-20591 tests: report the error, not the byte count

createmany kept the return value of read(), write() and lseek() in
the same variable it uses for its exit status, so a short write left
a bogus status behind and a successful one overwrote an error that
was already there. Keep the byte counts in a local of their own and
the errno in the status.

/dev/urandom is opened where it is used, on the first file that needs
it, rather than once per run whether or not anything is written. The
failure is then reported with the errno of the open that just failed,
which the old placement had already lost by the time it was noticed,
and a run that writes nothing does not open the device at all.

While there, let DEBUG_RMMOD through to the remote nodes the way
VERBOSE is, so that a test that sets it sees it on every node that
the test framework drives.
