--- Commit Message ---
LU-10026 csdc: tunable to disable compression on fallocate

fallocate is denied for compressed files because preallocating space
for a compressed file makes the compression useless. But sometimes it
could be preferable to deactivate compression and honor fallocate
instead.
So add a tunable for disabling compression on fallocate, 0 by default:
llite.*.prefer_fallocate_over_compr
Note disabling compression is possible only if none of the components
have been already initialized.

Add sanity-compr test_1031 to exercise this.
