LU-20485 misc: use LLVM automatic reference counting

We might be able to use LLVM's automatic reference counting [1] to
find ref count bugs in our kernel code. While this feature was
originally designed for Objective-C, the annotations work fine
on C. I was able to discover a few small bugs with this. This
warrants more discussion with the upstream Linux/LLVM maintainers
to understand if there is a path to adoption in the Linux kernel.

This is a PoC.

[1] https://clang.llvm.org/docs/AutomaticReferenceCounting.html
