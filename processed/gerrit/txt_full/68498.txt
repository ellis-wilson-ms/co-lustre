--- Commit Message ---
LU-17000 obdclass: drop dead sscanf() error checks

string_to_decimal() tests sscanf() for a negative return.  The kernel's
vsscanf() only ever returns the number of conversions performed, so
those branches are dead; the "rc < 1" tests that follow them are what
actually catches a failed conversion.
