--- Commit Message ---
LU-4009 osd-zfs: ordered transaction for zil integration.

Ordered transaction is used to satisfy the requirement that when a
transaction is committed, all transactions started before it should
also be committed.

There are two aspects of ordered transaction. One is about concurrency
control and its implementation is osd_tm.c; the other is about log
commit and replay and its implementation is osd_zil.c.

The files that utilize ordered transaction are as follows:
- osd_handler.c: transaction start and stop are modified here. In
  osd_trans_start(), transaction id is assigned and the started
  transaction is put in ordered queue. In osd_trans_stop(), the
  stopped transaction waits its turn and then triggers log commit
  and waits commit if it is synchronous.

- osd_object.c, osd_xattri.c and osd_io.c: transaction declaration
  and execution are modified. In declaration routines, update intent
  is declared; in execution routines, update intent is acquired and
  update is packed for logging.
