--- Commit Message ---
LU-10026 tests: more tests for csdc

- synthetic tests to cover all simple cases like full/partial
  write/overwrite/append/read which verifies the operations
  doing same IO to tmpfs
- a test simulating a bulk error
  to ensure all bufs/pages are released
- few tests simulating read/write/truncate to corrupted chunks
- a test checking how much IO different cases need
- add own fsx with compression enforced
- add own dbench with compression enforced
- add own iozone with compression enforced (slow)

tests: cleanup sanity-compr.sh

Fix style issues in sanity-compr (whitespace, variables).
Add check_and_set_extents_dense() helper in a few places.
Re-enable test_1012 now that server-side code is fixed.

DDN-bug-id: EX-10107
Was-Change-Id: I7f5e5b759a8081efed4700d1c963afde135e690f

tests: improve sanity-compr/1000c

the existing test doesn't take into account that allocations can be
done in few racing threads, thus allocation is not serialized. thus
it can be non-sequential, but still dense.
the test should sort filefrag's output by physical location first,
then count gaps.

DDN-bug-id: EX-10763
Was-Change-Id: Ie3e1122e549da0a181f8cf5dbb0aa4304d1c3157

tests: Use less data in csdc DIO iozone test

"EX-6266 llite: DIO fallback on compressed files" forces
to switch any DIO operation to the buffered one. This behaviour
breaks any iozone expectations and the test goes too slowly.
Having such an iozone test with DIO and compression is a good
idea, but let's reduce the testing file size so this test pass
for reasonable amount of time.

DDN-bug-id: EX-10445
Was-Change-Id: I8dee83398a4e5249ad254d061bafa89240feb2e2

tests: Use less data in iozone test

"EX-10445 tests: Use less data in csdc DIO iozone test" sets to
use 1/10 of available space for DIO iozone test. The same chage
should be done for buffered iozone test too, because the test it
too slow for large disks and slow VMs.

DDN-bug-id: EX-10445
Was-Change-Id: I40ca9783826448885cb4d8d3ca889d94df26f257

csdc: execute tests if compression is enabled

"csdc: Provide finer grained enable_compression control" patch
enables CSDC by default on all archs except aarch64 and ppc64le.
No need to execute enable_compression/disable_compression for
each test, so this test changes them to compression_enabled
check that skips test if compression is disabled for the arch.

This patch forces to skip compression tests for ppc64le and
aarch64 so they stop adding noise to the test results.

DDN-bug-id: EX-8981
Was-Change-Id: I2b5deba0672f3bad028f383cf1205e66c2b05529

tests: disable compressibility checks

some tests want to mix compressible and incompressible data for
verification. EX-8355 can disable compression for a period when
incompressible data met. disable this functionality in few
tests.
