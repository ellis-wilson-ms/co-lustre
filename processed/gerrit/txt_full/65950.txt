--- Commit Message ---
LU-20271 ptlrpc: clear rq_repdata in sptlrpc_cli_free_repbuf

For replayable requests like open/mcreate, the reply buffer might be
freed early while the request is still in the replay list.

When sptlrpc_cli_free_repbuf() is called, it clears rq_repmsg but
leaves rq_repdata and rq_repdata_len unchanged. If this request is
later replayed, ptl_send_rpc() hits an LBUG because it asserts that
rq_repdata must be NULL if rq_repbuf is NULL.

Clear rq_repdata and rq_repdata_len in sptlrpc_cli_free_repbuf() to
fix this.
