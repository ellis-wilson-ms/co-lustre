LU-20818 clio: copy unaligned DIO reads in parallel

An unaligned (including hybrid) DIO read is copied from the bounce
buffer to the user by the thread that completes each sub-DIO,
usually ptlrpcd, one sub-DIO at a time, and the IO cannot finish
until the last sub-DIO's whole copy is done.

Split that copy into the same page-aligned chunks as a write's:
the completing thread queues all but the first to the copy
workqueue, copies the first itself and waits for the rest, so the
sub-DIO is still whole when its end_io carries on.  A thread that
is neither a kernel thread nor the IO's owner keeps the single
thread copy, which handles that case.  `dio_copy_chunk_kb` now sets
the chunk for both directions.

A chunked copy fails the read if any of it is short, where
the single thread path returns the bytes it managed, which
cl_sync_io_note() records only if negative, so it passes as
success.  The stricter result is the right one, but the
difference now depends on dio_copy_chunk_kb.
