LU-20344 lnet: introduce lnet_peer_discovery_mode parameter

The lnet_peer_discovery_disabled module parameter is a boolean. It
cannot hold the NID filter modes that a later patch adds.

Add the lnet_peer_discovery_mode module parameter:

    0 - discovery off
    1 - discovery on, merge all NIDs (default)

The deprecated lnet_peer_discovery_disabled parameter still works.
Each setter also updates the other parameter, so the last write wins.
Callers use lnet_discovery_off() to get the effective state. A write
to the deprecated parameter warns while LNet is not running, as at
module load.

"lnetctl set discovery <n>" now writes the mode. Each value other than
0 or 1 now fails, also in "lnetctl import". Before, each value other
than 0 enabled discovery.
