LU-20248 tests: fix race in check_gss_daemon_nodes

check_gss_daemon_nodes counts the lsvcgssd daemons parented to init
to ignore the short-lived child lsvcgssd forks at startup for the
Miller-Rabin speedtest (LU-17175).  It did so by running "ps -o
ppid=" per pgrep'd PID; when the child exits in between, ps is empty
and the test becomes "[ -ne 1 ]", a bash unary operator error.  The
"||" arm then inflates the count, so a healthy daemon is reported as
"2 instance of lsvcgssd" and start_gss_daemons returns 5.

Replace the per-PID loop with "pgrep -P 1 -c" over one do_nodesv
call: an unreachable node or zero count makes pdsh return non-zero,
and a count above one is caught while scanning the output.
