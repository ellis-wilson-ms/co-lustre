--- Commit Message ---
LU-20055 tests: Check that VFS leases are refused

Nothing in the tree exercises llite's ->setlease, so a kernel compat
change that quietly stopped defining HAVE_SIMPLE_NOSETLEASE would go
unnoticed. Add a multiop k[R|W|U] op for fcntl(F_SETLEASE) and a
sanity case asserting a read lease is refused on a regular file.

Directories are not covered: fcntl_setlease() rejects a directory on
every kernel, so such a case could not tell a patched client from an
unpatched one. Only F_SETDELEG (v6.19+) reaches ->setlease for a
directory.
