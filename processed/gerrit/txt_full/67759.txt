LU-20107 nrs: add node tier hierarchical scheduling

Add a node tier above the CPT tier of TBF and mClock. When the policy
starts with "global=1", a node tier rule gets one parent class for the
service. The node tier divides the rule rate over the CPT tier rules.
Each CPT tier rule owns one shared class bucket.

    lctl set_param *.*.ost_io.nrs_policies="mclock projid global=1"
    nrs_hsch="mclock start r1 projid={100} rate=100 root=0 node=0"
    nrs_hsch="mclock stop r1"

The new nrs_hsch entry starts, stops and lists the node tier rules. A
rule for both queues divides its rate by 2 * ncpts. A rate below the
divisor returns -EINVAL. A TBF node tier start must name a rate.
Without one, it returns -EINVAL. A stop must name every queue of the
start.
The per-CPT rule dump adds "share", "global" and "clsid".

Each tier stops only its own rules. A per-CPT stop of a global
rule returns -EPERM. A failed node tier start thus cannot remove
a per-CPT rule of the same name. A change of a global rule in the
per-CPT rule file takes the queues of the start. A change that
names other queues returns -EINVAL. nrs_hsch prints a weight only
when the node tier command names one.

Add sanityn/test_77w{a,b,c,d}.
