--- Commit Message ---
LU-19403 llapi: Move nodemap fileset functions

Move nodemap_fileset_add()/nodemap_fileset_del()/
nodemap_fileset_modify() from obdctl to liblustreapi
(nodemap_set_fileset() stays for compatibility).

jt_nodemap_fileset_modify()'s getopt_long() optstring was missing
'o' and a required-argument colon for 'r', so -o/-w silently fell
through to the default case. Its option handling moves to alt/
primary/ro/rw booleans, and llapi_nodemap_fileset_modify() takes
const bool *alt/*ro instead of type/access strings, so a caller
can't pass a plausible but server-rejected spelling.

The three jt_nodemap_fileset_*() handlers now return the library
result directly, sanity-sec.sh gains version-aware shell variables
for pre-2.16.51 interop, and man3 pages are added.

Fixes: 1e94980e4eb1 ("LU-18357 ptlrpc: Add in-place modification of filesets")
