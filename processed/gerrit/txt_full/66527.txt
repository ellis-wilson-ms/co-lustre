--- Commit Message ---
LU-19079 krb: use .lgss to specify principal

Allow the .lgss file inside the client mount point to contain a
reference to the Kerberos principal to use, with the syntax:
krb5princ=<full Service Principal Name>

This is an alternative to the 'krb5princ' mount option, designed for
easier automated implementation.
