--- Commit Message ---
LU-18298 pcc: pick up a lapsed copy in the detach ioctl

pcc_ioctl_detach() returns success without removing the HSM archive
when the client has no PCC inode attached, even though the copy is
still valid on the backend. "lfs pcc detach -k" leaves exactly that.

It has always relied on the caller having opened the file first, so
that pcc_file_open() re-attached it. Do that same PIT_OPEN attach in
the ioctl instead, under the dataset gating open uses, so no layout
is refreshed and no lock is taken.

The next patch stops lfs pcc detach opening the file at all, which
is what makes sanity-pcc test_16 depend on this.
