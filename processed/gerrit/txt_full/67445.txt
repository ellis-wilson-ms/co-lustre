LU-17000 ldlm: Fix Dereference before null under ldlm_cli_enqueue_fini

'req && in if (req && req->rq_svc_thread)' is the stale part.
This patch fixes Dereference before null check reported
by coverity run under function ldlm_cli_enqueue_fini() by
dropping the 'req'. As a NULL 'req' would already have crashed
before.
