LU-20527 tests: fix precreated object count in sanity 27y/220

sanity test_27y and test_220 count the precreate window as
"last_id - next_id", one short: precreated_ost_obj_count() in
test-framework.sh reads the same pair as "last_id - next_id + 1".  An
OSP reports next_id == last_id + 1 whenever the window is empty, so the
count is then -1, which neither test catches - and createmany never
sees a count at all, because a trailing "-1" is its deprecated "run for
N seconds" form:

  $ createmany -o f -1
  warning: '-runtime' deprecated, use '-t runtime' instead
  total: 1699 open/close in 1.00 seconds: 1698.78 ops/second

Count the window as precreated_ost_obj_count() does and skip when it is
empty, before test_220 sets up the fail_loc and the pool.
