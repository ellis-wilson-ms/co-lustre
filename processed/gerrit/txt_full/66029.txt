--- Commit Message ---
LU-20285 llite: identify mmap use case by checking CIT_FAULT

Replace the indirect vui_ra_valid heuristic
with a direct check of io->ci_type == CIT_FAULT
to determine if the read is triggered by mmap page fault.

The original code assumed mmap access when readahead is invalid,
which could be incorrect in some scenarios.
The new approach explicitly checks the I/O type
(CIT_FAULT explicitly indicates the I/O is happening
due to a page fault from a memory-mapped region),
making the logic more accurate and easier to understand.
