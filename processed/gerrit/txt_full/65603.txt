--- Commit Message ---
LU-17238 llite: track validity of cached lli_posix_acl

ll_get_acl_common() (invoked during an access() syscall)
systematically sends getxattr RPC if lli_posix_acl is not set.
However a NULL value could be valid if no ACLs are set on the inode.
lli_posix_acl is updated on MDC lock intent RPC reply.

Add the flag LLIF_ACL_VALID to lli->lli_flags to explicitly track the
validity of a NULL lli_posix_acl. This allows the system to rely on
the cached value instead of always sending an RPC.
