--- Commit Message ---
LU-20496 efalnd: Wait for connection to be idle before destroy

Restore the timeout check before destroying connections in the drain
stage. The scan/drain split removed the timeout gate that existed in the
original kefalnd_cleanup_ni_conns, allowing connections to be destroyed
as soon as TX lists appeared empty.
This is not safe since we can still receive completions from the device
until the connection is considered.
