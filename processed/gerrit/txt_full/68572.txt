--- Commit Message ---
LU-20682 llite: validate xattr value in ll_xattr_set()

ll_xattr_set() swabs the LOV and LMV EA from setxattr(2) without
checking the value.  removexattr(2) and a zero-length setxattr(2)
hand it value == NULL, and a short value carrying a big-endian LOV
magic or the "lmv" name is rewritten past the end of the kernel
buffer.  A composite value long enough for its header still escapes
it: the entry walk follows lcm_entry_count and lcme_offset out of
that same value.

Touch a value only when it exists and holds the whole header its
magic describes, and bound the composite walk by lcm_size and by
each entry's lcme_size.  lcm_size comes out of the value as well,
so lustre_swab_lov_comp_md_v1() now takes the buffer length from
its caller and reports whether it swabbed anything, which
lod_declare_layout_purge() needs before reading the layout back.
Bound lmm_stripe_count by the buffer size in
lustre_swab_lov_user_md() before swabbing the objects too, since
its callers size the buffer from the unswapped header.

A foreign component ended the entry walk, leaving the components
after it unswapped; skip it instead.
