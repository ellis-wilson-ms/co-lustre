--- Commit Message ---
LU-18586 utils: allocation API for find_param struct

Since sizeof(struct find_param) is part of the lib ABI, programs built
against older headers may perceive sizeof(struct find_param) to be
smaller than expected by the lib, possibly causing lib functions to
interact with unrelated caller stack space in an unpredictable way.

Using llapi_find_param_{alloc,free} functions to allocate the
find_param struct means the find_param allocation will always be of
the size expected by the lib, reducing risk.
