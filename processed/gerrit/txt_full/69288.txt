LU-20840 mdt: don't re-count MDS-MDS conns on reconnect

mdt_connect_internal() increments mdt_mds_mds_conns for every MDS-MDS
(non-lightweight) connection, but it is called on both connect and
reconnect while mdt_obd_disconnect() decrements the counter only once
per export. A reconnect on a live inter-MDT export therefore leaks +1.

The inflated counter is used as the effective MDT count when capping
the directory auto-split target stripe count in mdt_auto_split() and
when deciding whether to queue a directory for auto-split in
mdt_getattr_internal(). On a 2-MDT filesystem the count can climb
past the real MDT count, so the target stripe count exceeds the
number of MDTs and LOD rejects the split with -E2BIG.

Only increment mdt_mds_mds_conns (and enable SLC) on the initial
connect, so the counter stays balanced with the single decrement in
mdt_obd_disconnect().
