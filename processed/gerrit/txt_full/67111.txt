--- Commit Message ---
LU-20453 mdc: fix memory leak in mdc_device_alloc()

When class_name2obd() fails to find the OBD device, the function
returns an error without freeing the osc_device structure allocated
earlier. This causes a memory leak on device initialization failure.

Add cleanup of the cl_device and osc_device before returning error,
matching the cleanup pattern already used when mdc_setup() fails.

Fixes: 68ff85b8858e ("LU-3285 mdc: add cl_device to the MDC")
