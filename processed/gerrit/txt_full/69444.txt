LU-18687 obd: cleanup kobject default groups handling

With our kobject abstraction we can simplify _get_attr_matches().
Currently if we drop it into a kernel tree this breaks the build.
Make it buildable in tree and out of tree by having
_get_attr_matches() now always walks kobj_type.default_groups[].
We can do this because our compat layer maps default_attrs of
older kernels to default_groups.
