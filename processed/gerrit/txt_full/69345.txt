LU-20861 socklnd: set bvec offset with bvec_iter_advance()

Linux commit b539aeacf8cc ("block: rename bi_bvec_done"), in
v7.3-rc1, renamed bi_bvec_done to bi_offset, breaking the
designated initializer in ksocknal_iter_for_each_range().

Use bvec_iter_advance() to initialize the offset without depending
on the field name. Initialize bi_size to skip + bytes so advancing
by skip preserves the original checksum range. This walk only runs
for the optional receive checksum, which is only sent on V2
connections.

socklnd_lib.c now compiles without warnings against v7.3-rc5
(ktest mainline/ml); the build still fails elsewhere on the
strncpy() removal, see LU-20434. A userspace harness compiling
this function against bvec.h from v7.2 and v7.3 produced the same
byte ranges as the original over about a million generated cases.
