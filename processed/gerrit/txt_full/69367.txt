--- Commit Message ---
LU-20076 tests: fewer remote commands to wait for deletes

wait_delete_completed() is called about 100 times in the main test
scripts.  Even when nothing is pending, it runs one remote command
per MDS node for the osc sync counters, then another on all MDS nodes
for osp.*.destroys_in_flight.  sync_all_data_mdts() runs two separate
remote commands on the same MDS nodes.

Check both counters on all MDS nodes in one remote command first, and
only wait with wait_delete_completed_mds() and wait_destroy_complete()
if anything is pending.  Set both force_sync parameters in one remote
command in sync_all_data_mdts().

Average of 2x20 calls with nothing pending, on 3 nodes (MDS with 2
MDTs, OSS, client) over ssh.  With more MDS nodes, the old
wait_delete_completed() makes one more remote call per MDS node:

                          before  after
  wait_delete_completed()  0.40s  0.21s  (-48%)
  sync_all_data_mdts()     0.40s  0.20s  (-50%)
