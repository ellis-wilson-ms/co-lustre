LU-20579 tests: use ip(8) for the test_109 interface alias

test_109 added and removed the alias with ifconfig, which comes
from the deprecated net-tools package and is absent on minimal
RHEL 9 images. The test failed at setup on such nodes.

Use ip(8), as setup_fakeif() in the same test already does. These
were the only two ifconfig calls in the suite. The alias address
now carries an explicit /31, matching FAKE_IP, in place of the
classful /8 that ifconfig applied to a 10.x address.

Drop the paired address delete. cleanup_fakeif() removes the veth
pair on the next line and takes the alias with it. The delete was
fatal, so a stale address turned an otherwise passed test into a
failure and skipped the remaining teardown.
