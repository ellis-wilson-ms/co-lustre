--- Commit Message ---
LU-20806 osd-ldiskfs: free the directory iterator's LSM blob

The fake file a directory iterator reads through gets an LSM
blob when the iterator is set up, but tearing the iterator down
never frees it, so each directory iteration on an ldiskfs target
leaks one.  An MDT under a two-hour rename benchmark held over a
million of them.  Free it at teardown.  The setup error paths
now give the blob and the read buffer back too; they leaked the
buffer or left the per-thread one marked in use.

Fixes: bdb39e8390c4 ("LU-19388 osd: remove calls to alloc_file_pseudo()")
