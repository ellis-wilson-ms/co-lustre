LU-18687 llite: remove SLAB_MEM_SPREAD entirely

SLAB_MEM_SPREAD only ever had an effect with CONFIG_SLAB, where
it enabled cpuset memory spreading in alternate_node_alloc();
SLUB always ignored it. No supported distro kernel was built
with CONFIG_SLAB (RHEL and Ubuntu have shipped SLUB throughout),
and the SLAB allocator itself was removed in kernel v6.8. The
flag was deprecated to zero in v6.9 and removed in v6.10, with
all in-kernel users dropped.

Remove the last user in super25.c and the compat definition,
matching the upstream kernel-wide cleanup. No functional change.
