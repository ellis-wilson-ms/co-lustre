--- Commit Message ---
LU-20090 nrs: add allowed dynamic classification types for TBF

Add an "allow=" key to the TBF policy start command. The key names a
classification type that a dynamic rule can use. A rule starts only
when its type equals an allowed type. A "nid" rule therefore needs
"allow=nid", even under "allow=nid+opcode".

    nrs_policies="tbf nid classify=dynamic allow=nid allow=nid+opcode"
    lctl get_param -n ost.OSS.ost_io.nrs_tbf_allowed_types

The head sorts the allowed types in descending order of granularity,
for the class bucket lookup of the next patch.

nrs_tbf_parse_cmd() now returns the error code of the parser, not
-EINVAL for every error.

Add sanityn/test_77tc.
