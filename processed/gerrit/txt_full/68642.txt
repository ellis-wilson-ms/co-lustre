--- Commit Message ---
LU-17000 obdclass: drop the dead cfg NULL path in llog parsing

class_config_parse_llog() still branches on a NULL
config_llog_instance: it substitutes class_config_llog_handler()
as the callback and skips the cfg_last_idx bookkeeping.  That
branch cannot work, since the handler dereferences cfg for every
OBD_CFG_REC it processes, and it cannot be reached either:
mgc_process_cfg_log() and mgc_process_server_cfg_log() are the
only callers and both pass &cld->cld_cfg.

Drop the branch, the two companion cfg tests and the
lpcd_first_idx initializer that only the NULL path relied on.
No assertion is added in its place: cfg is dereferenced
unconditionally right below.
