LU-19921 ptlrpc: fix network matching

In sptlrpc_rule_set_choose() the network comparison mistakenly
use:
	__be16_to_cpu(nid->nid_num) != r->sr_netid

Because r->sr_netid stores the full 32-bit LNet network ID (created
via LNET_MKNET(type, num) from libcfs_str2net()), comparing it
against only the 16-bit network number (nid->nid_num) causes network
matching to fail for all networks with a non-zero network type
(e.g. tcp, o2ib).

Use LNET_NID_NET(nid) instead, which returns the full 32-bit network
ID (type and number), correctly matching r->sr_netid.
