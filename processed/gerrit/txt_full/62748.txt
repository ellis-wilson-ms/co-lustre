LU-16518 osc: fix -Wunused-but-set-variable warnings

Clang warns about variables that are set but never used. Remove
cksum_counter from osc_brw_fini_request(), since it is only ever
written and never read.

In osc_lru_reserve(), rc is assigned from l_wait_event_abortable()
but never checked. This is more than an unused variable: a fatal
signal can not interrupt the wait, since the loop just retries
with the signal still pending. Check rc and report that nothing
was reserved if the wait is interrupted. No LRU slots are held at
that point, so there is nothing to give back. The caller then
falls back to reserving slots per-page in osc_lru_alloc(), which
already returns -EINTR when its wait is interrupted.
