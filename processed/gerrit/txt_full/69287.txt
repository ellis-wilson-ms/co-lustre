--- Commit Message ---
LU-20755 tests: fix sanity-sec/5, 64a, 64h, 64j, 64k for older servers

test_5 checks that l_getidentity returns EIDRM for a nonexistent user.
That only happens on servers with LU-19996, an older MDT logs a
different errno, so the test can never pass. Skip test_5 on older
servers.

test_64a and test_64h always ask for the "projid_set" RBAC role, even
on servers that don't have it, so the nodemap_modify fails with
EINVAL. Only ask for the role when the server supports it. For the
negative checks in test_64a, fall back to rbac="none" so they still
run on older servers. Also improved foreign_ops gating in test_64a.

Improve version gating in test_64j to skip servers that do not
support the projid_set role.

Improve version gating in test_64k to skip servers that do not
support the foreign_ops role.

Test-Parameters: trivial
Test-Parameters: testlist=sanity-sec serverversion=2.16 env=SANITY_SEC_EXCEPT="45 47 48b 49"
Test-Parameters: testlist=sanity-sec serverversion=2.17 env=ONLY=64h,64j,64k
