LU-16904 tests: allow sanity to run with PFL layout

Allow sanity.sh to run and pass with fs_STRIPEPARAMS that contains
a multi-component PFL layout.

Once fixed we can finally set the default filesystem-wide layout
to use PFL at creation time, and improve test coverage as well.

Fix sanity.sh test_101i, use the plain file layout the test expects.

Exclude sanity subtests that are failing when the default filesystem
layout is not a "plain" 1-stripe layout until they are fixed:
- test_27D, test_27M, test_34h, test_44f, test_56*, test_184d
- test_204a/e, test_600a, test_853

Apply fs_STRIPEPARAMS default layout for all test scripts if set.
Add ${TESTSUITE}_STRIPEPARAMS override the global layout if set.

Inherit compr_STRIPEPARAMS in sanity-compr.sh.  Return errors from
these sub-scripts, otherwise the scripts report subtest failures to
the console but the overall sanity-compr session passes.

Test-Parameters: trivial
Test-Parameters: testlist=sanity env=fs_STRIPEPARAMS="-E 1M -c1 -E eof"
Test-Parameters: testlist=sanity env=fs_STRIPEPARAMS="-E 64k -c 1 -E 1M -c 2 -E eof -c 4 -S 4M"
