--- Commit Message ---
LU-20909 llite: copy only reply bytes for dir read-on-open

ll_dir_finish_open() copies PAGE_SIZE bytes from the inline reply
into each folio, but the MDS returns only rep_size bytes, mostly
whole lu_dirpages.  On a client with pages larger than 4KiB a
small directory returns a single 4KiB lu_dirpage, so the copy reads
up to PAGE_SIZE - 4KiB past the end of the reply buffer.

Copy only the bytes left in the reply and zero the rest of the
folio.  Also limit lu_pgs to the folios actually allocated, so a
folio allocation failure partway through does not leave lu_pgs
unconsumed and trip the LASSERT in mdc_adjust_dirpages().
