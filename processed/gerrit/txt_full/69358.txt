--- Commit Message ---
LU-20858 lnet: reject invalid network names in route queries

An invalid network name passed to lnetctl route show --net is
converted to LNET_NET_ANY and treated as an unfiltered query.
This returns success, with no output when no routes exist.

Check the parsed network and return "cannot parse net" with
-ENOENT on failure, matching the net show handler. Queries
without a network filter continue to show all routes.
