LU-20610 build: Install mount.lustre_tgt symlink

/sbin/mount.lustre_tgt has never been installed, due to four bugs:
1) $(SERVER) is not a make variable, so the guard is always
   false and the symlink is never created;
2) the symlink target is an absolute path under $(DESTDIR),
   which no longer exists once the package is installed;
3) the symlink is created in $(sbindir), while mount.lustre
   is installed in $(rootsbindir);
4) the spec file lists the path as %ghost, which keeps it
   out of the package payload.

Use an automake conditional, create a relative link in
$(rootsbindir), and package the symlink as a regular file.
