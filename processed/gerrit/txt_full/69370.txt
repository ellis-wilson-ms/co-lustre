LU-20076 tests: only mark the first poll in wait_update_cond

wait_update_cond(), used by wait_update() and wait_update_facet() in
almost 300 places, polls a remote command about once a second until
it returns the expected value.  With VERBOSE, do_node() prints "CMD:"
and also sends "lctl mark" to the node for every poll, so each poll
is two round trips and the test log and debug log get a copy of the
same command each second.

Only log and mark the command for the first poll, and run the rest
of the polls with do_node -q.

Average of 2x20 VERBOSE do_node() polls over pdsh/ssh:

  marked   quiet
  0.36s    0.18s  (-50%)

A wait_update() that took 7 polls logged 7 "CMD:" lines before and 1
after.
