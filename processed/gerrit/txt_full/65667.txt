--- Commit Message ---
LU-19001 osp: fix misplaced unlikely() in opd_gap_count check

The current check in osp_create uses unlikely(d->opd_gap_count) > 0,
which applies the branch prediction hint to the raw value instead of
the full comparison. Change it to unlikely(d->opd_gap_count > 0)
so the hint matches the intended condition and the code reads
unambiguously.
