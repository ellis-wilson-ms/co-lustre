--- Commit Message ---
LU-12187 tests: skip llapi_layout_test 37 for old MDS

sanity test_27D runs llapi_layout_test, whose subtest 37 ("verify
mirror count and mirror ids for existing files") needs the arbitrary
mirror id support added to the MDS in commit 5c24d600986b.  test_27D
gates its other subtests on the server version but not this one, so an
interop run against an older server fails there unless the caller sets
SKIP27D="-s 37" by hand, which several patches now carry in their
Test-Parameters.

Gate subtest 37 on the server version like the rest, so no caller
needs the exception.

Test-Parameters: trivial testlist=sanity serverversion=2.17
