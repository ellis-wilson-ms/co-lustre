--- Commit Message ---
LU-20808 target: read the xattrs an IT_MDT_TO_MDT_READ names

Run the OUT_XATTR_GET reads an IT_MDT_TO_MDT_READ carries, and
OUT_XATTR_LIST, on the MDT owning the locked object while it grants
the lock. Each comes back as from OUT_UPDATE: the value as stored, or
-ENODATA for an absent xattr, which the requester caches as readily
as a value. That spares it a round trip in the common case of a
directory with no default layout or ACL.

The values share the room the requester asked for, in order. One that
does not fit in what is left is read again with no room, which gets
its size alone, as OUT_XATTR_GET does for an empty buffer. The
requester caches that size, and reads the value itself when it needs
it.
