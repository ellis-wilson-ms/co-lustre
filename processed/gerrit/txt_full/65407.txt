--- Commit Message ---
LU-20090 nrs: add dynamic granularity classifier for TBF

The TBF policy start command sets one classification type for the
head. A rule of another type cannot start.

Add the dynamic classifier. Each rule takes its class type from its
own match conditions. The head keeps a mask of the types of its live
rules. The key of a dynamic head holds only those fields. The rule
dump adds a "type=" field.

nrs_tbf_id_cli_set() now clears each ID field that the rule does not
match. A "uid" policy put the gid in the key too. One uid under two
gids then got two class buckets, each with the full rule rate.

The rule stop path now holds th_rule_lock over the list removal.

Add sanityn/test_77t{B,h,b}.
