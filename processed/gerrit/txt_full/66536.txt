--- Commit Message ---
LU-20342 lnet: support discarding received bulk data

Introduce LNET_MD_DISCARD option to allow LNet and socklnd to discard
incoming bulk data payloads using MSG_TRUNC, avoiding memory copy
overhead for performance testing.

Integrate this into lnet_selftest by adding a new check mode
LST_BRW_CHECK_DISCARD, exposed to the user-space lst tool via
'check=discard' and 'skip_rx_copy' options.

LNet selftest: Throughput between two 200Gbps nodes over TCP.
