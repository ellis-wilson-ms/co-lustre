--- Commit Message ---
LU-17000 compat: Fix resource leak in ll_shrinker_alloc

ll_shrinker is allocated early. If shrinker_alloc() fails
it leaves ll_strinker dangling on exit. This patch fixes
leak on a fail path while allocating 'struct shrinker'

Note that leak only exists after LU-19080 (branches having
LU-18175 but no LU-19080 does not have this leak)

Also, Not introduced by this patch, this patch also
handles case where kvasprintf_const() returns NULL
and then dereferences it. This patch also uses kfree_const()
instead of kfree()

CoverityID: 504221 ("Resource leak")
Fixes: 3ccd941e2de ("LU-19080 compat: match kernel shrinker protocol")
