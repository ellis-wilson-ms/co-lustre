--- Commit Message ---
LU-12597 tests: remove comma_list for nodes_list

Remove comma_list from "nodes_list" callers and related cleanups.

facets_nodes(), nodes_list(), remote_nodes_list() and mgs_node()
now return a comma-separated list, so callers do not need to
wrap them in comma_list() any more.

all_mdts_nodes() now falls back to the mds_HOST from the config
when no mds${i}_HOST is set, which is the case until facet_host()
has been called.  It previously returned an empty list.

remote_mgs_nodsh() tested $ost_HOST, which says nothing about the
MGS, so drop the term and leave the PDSH test.
