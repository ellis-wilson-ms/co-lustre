--- Commit Message ---
LU-17296 nrs: order BRW RPCs by offset inside an mClock class

The queue of an mClock class bucket is FIFO. A fair shared HDD OST
loses the seek order that the ORR policy gives.

Add a "locality=" key to the mClock policy start command. Each class
bucket then also sorts its BRW RPCs by the offset of the first
fragment. Equal offsets keep the arrival order. A class can hold many
objects, so the key helps most with one large object for each class.
TBF returns -EINVAL for the key.

The YAML rule dump adds an offset_insert counter. The mClock
D_RPCTRACE dequeue line shows the BRW offset. The mClock request grows
to 64 bytes.

Add sanityn/test_77xe.
