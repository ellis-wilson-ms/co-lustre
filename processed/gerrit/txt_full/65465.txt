LU-20184 nrs: extend TBF rate to support bandwidth (BPS) mode

The TBF policy limits a rule in RPCs per second. With mixed I/O sizes,
the RPC count does not show the cost. 100 writes of 4 MiB cost much
more than 100 writes of 4 KiB.

Add a bandwidth (BPS) mode. The "bps=" rule key sets a byte rate for
read and write RPCs, in MiB/s by default. The "iops=" key sets an RPC
rate, and a rule can set both. The rule dump adds a "bps=" field.
"realtime=" with "bps=" returns -EOPNOTSUPP. A rate of 0, or of
LPROCFS_NRS_RATE_MAX or more, returns -ERANGE, not -EINVAL.

    nrs_tbf_rule="start r1 projid={100} iops=1000 bps=5MB/s"

Read limit 5 MiB/s, write limit 15 MiB/s, result in MB/s:

    blksz   4KiB    64KiB   128KiB  256KiB  1MiB
    write   5.7     14.6    14.8    15.3    15.7
    read    4.6     5.0     5.1     5.2     5.3

Add sanityn/test_77u{a,b,c,d}.
