--- Commit Message ---
LU-20684 lod: timestamp component initialization

Set lcme_timestamp when a composite layout component is first
initialized. Preserve timestamps used by replay, NOSYNC, and EC.
Avoid assigning timestamps to released placeholders.

Clear ordinary timestamps copied to new SEL components so they are
timestamped at their own initialization. Add PFL, SEL repeat and
replay, HSM restore, and layout intent replay coverage. Document the
timestamp semantics.

Parse component flags independently from the timestamp printed after
them. Resolve the generated SEL repeat component by ID instead of
assuming it has component ID 2.
