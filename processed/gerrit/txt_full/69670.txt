LU-15909 lnet: spill sends to a net with a free credit

A peer can have a fast net and a slow net, for example o2ib and tcp.
With a UDSP priority rule on the fast net, every send uses that net.
When the fast net has no free credit, LNet queues the message. The
slow net stays idle, even when it has free credits.

Add the lnet_spillover tunable, default 0. When it is 1, LNet can
select again without the selected net. It does so only when every
equal or better path on that net would queue the message. Health and
selection priority decide which path is better. The new path must be
as healthy. It must also have a free peer credit and a free NI credit.

Move the latency_stats set and show code into shared helpers
for a boolean module parameter. The spillover tunable uses them.

    lnetctl set spillover 1
    lnetctl global show | grep spillover
        spillover: 1
