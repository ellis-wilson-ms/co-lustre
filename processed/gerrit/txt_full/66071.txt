LU-16738 tests: skip conf-sanity/161 if /etc/hosts readonly

The recently-added conf-sanity.sh test_161 was failing in Janitor
testing since the /etc/hosts file cannot be modified to add a fake
MGS hostname to it.

If a hostname already exists for the MGS then there is no need to
add a fake one, making the /etc/hosts read-only status irrelevant.

If there is no MGS hostname and /etc/hosts is read-only, then skip
the end of the test since it needs a hostname and not an IP address.

Add 'stack_trap cleanup' so a failure doesn't leave a mess behind.
