--- Commit Message ---
LU-17000 mgs: drop a dead NULL check in mgs_direntry_free()

The LASSERT(list_empty(&de->mde_list)) above the "if (de)" already
dereferences de unconditionally, so the test cannot save a NULL
pointer - the function would have died on the line before.  All 14
callers free an entry they have just taken off a directory list with
list_for_each_entry_safe(), so nothing passes NULL in a build
configured with --disable-libcfs-assert either.

Reported by smatch as "variable dereferenced before check 'de'".
