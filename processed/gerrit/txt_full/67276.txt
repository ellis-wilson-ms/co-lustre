LU-16518 sec: remove unused llcrypt compat functions

... since they are no longer used. llcrypt_release_ctx() and
llcrypt_enqueue_decrypt_work() lost their last (and only)
caller in libcfs/libcfs/crypto/bio.c when that file was
removed. llcrypt_get_ctx(), llcrypt_handle_d_move(),
llcrypt_ioctl_get_policy(), llcrypt_match_name(),
llcrypt_prepare_lookup() and llcrypt_encrypt_symlink() were
imported verbatim from the in-kernel fscrypt code and never
had a caller in Lustre, which uses its own overlays (e.g.
ll_prepare_lookup()) and the __llcrypt_* variants directly.
The corresponding fscrypt_* macro mappings in lustre_crypto.h
are removed as well.

Also remove the machinery those functions relied on, which is
now dead weight: struct llcrypt_ctx and its preallocated pool
(along with the llcrypt_free_ctxs list, llcrypt_ctx_lock,
llcrypt_ctx_cachep and the num_prealloc_crypto_ctxs module
parameter) and the llcrypt_read_workqueue, which was only
ever allocated and destroyed.

Fixes: d328818a456d ("LU-12275 sec: remove bio functions in fscrypt compat")
Fixes: a813e8187009 ("LU-12275 sec: add llcrypt as file encryption library")
