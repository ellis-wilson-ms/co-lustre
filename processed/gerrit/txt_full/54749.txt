--- Commit Message ---
LU-17740 mds: remove user_xattr,acl MDT options

Remove the legacy user_xattr and acl options from Lustre's
server mount options. Both are normally enabled in ldiskfs,
but persisted superblock options can disable them. Report the
actual backing mount settings so the MDT grants only the
capabilities that are available. Strip every occurrence of
legacy options so duplicates do not override the defaults.

ZFS no longer accepts noacl as a server mount option. ACLs
remain enabled, so remove the unused ACL state and checks.

Clients still support (no)user_xattr. A client can disable
user xattrs locally, but the server also rejects them when
the backing filesystem has them disabled.

No backing filesystem now requires an explicit mandatory
mount option. Remove the mandatory-option checks and their
unused arguments from the formatting tools.
