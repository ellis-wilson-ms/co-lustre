--- Commit Message ---
LU-20642 tests: pin fsname in conf-sanity 108 helpers

The disk images restored by conf-sanity tests 108a/108b hard-code
the fsname "lustre" in CONFIGS/ and last_rcvd, so the whole test
must use that name regardless of $FSNAME. LU-11490 parameterized
the replace_nids and lfsck_start calls, which fail when FSNAME is
not "lustre".

Pin a local fsname in both tests and use it throughout to make the
constraint explicit.

Fixes: 134f3eced153 ("LU-11490 tests: use variable for file system name")
