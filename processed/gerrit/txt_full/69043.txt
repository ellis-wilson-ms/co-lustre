LU-18687 build: convert most cfs_timer users to the kernel API

With the removal of pre-5.0 kernels only one difference exists
for the kernel timer API. We can simplify our code with using
the latest API directly. Only timer_container_of() is new so
add a m4 test and create a wrapper if not present. Fix an old
gnilnd bug using the wrong timer callback.
