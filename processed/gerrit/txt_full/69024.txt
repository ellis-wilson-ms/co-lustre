LU-20772 socklnd: remove broken TCP backoff support

The TCP_BACKOFF_INIT and TCP_BACKOFF_MAX socket options were never
part of mainline Linux. They come from the "Customizable TCP backoff
patch" that Ben Woodard and Brian Behlendorf posted to netdev in
September 2006 for LLNL's oversubscribed gigE clusters, where
thousands of TCP streams backed off in lock step:

  https://lwn.net/Articles/202398/

No kernel defines the options, so the configure grep for TCP_BACKOFF
never succeeds and SOCKNAL_BACKOFF has been compiled out on every
build for years. Even if a kernel did define the options, the code
would no longer build: it calls kernel_setsockopt() directly, which
was removed in Linux 5.8, and the block was never converted to
sockptr_t like the neighbouring keepalive and IPv6 code.

Remove the LN_CONFIG_BACKOFF configure macro and --disable-backoff
switch, the backoff_init and backoff_max module parameters, the
tunable pointers, the setsockopt block, and the backoff/nobackoff
Debian build profiles.
