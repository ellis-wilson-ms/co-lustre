LU-20797 llite: add SET I/O scope ioctl

FLR designated-mirror I/O is tied to LL_IOC_FLR_SET_MIRROR(long)
and cannot name a stripe or an object. Add LL_IOC_SET_IO_SCOPE and
struct ll_ioc_io_scope.

The enum defines FILE, MIRROR, STRIPE, and OBJECT. This patch
implements FILE and MIRROR. STRIPE and OBJECT return -EOPNOTSUPP
and are not stored. Clearing is a SET of an all-zero FILE scope,
the same as SET_MIRROR(0). llapi_io_scope_clear() is that SET.

SET_MIRROR remains an alias for {MIRROR, id}, so llapi_mirror_set()
is unchanged. It now rejects ids above MIRROR_ID_MAX at ioctl time
instead of failing later at I/O. Non-FILE scopes require O_DIRECT.
SET_MIRROR(0) and llapi_io_scope_clear() no longer require O_DIRECT,
since clearing does not issue mirror I/O.
Unused identity fields, flags, and padding must be 0.

fd_io_scope replaces fd_designated_mirror. ll_io_scope_init()
copies a MIRROR scope into ci_designated_mirror.

A caller-supplied layout version is sent only for an FLR file, where
lov_io_mirror_init() checks it against lsm_layout_gen. On a non-FLR
file the version is cleared, so it is not stored in the OST object.

llapi_io_scope_set(3) documents the user interface.
llapi_io_scope_clear(3) is a link to that page.

sanity-flr test_213a covers the reserved scopes, a FILE set, and
mirror resync through the SET_MIRROR alias. test_213b writes a
non-FLR file with a caller-supplied layout version and checks that
the OST object does not record it.
