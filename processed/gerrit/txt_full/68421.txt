--- Commit Message ---
LU-20651 osd: zero-init map in osd_declare_write_commit

osd_is_mapped() uses the caller's map as an extent cache. The first
call in osd_declare_write_commit() read uninitialized m_lblk/m_len/
m_flags. Initialize map to zero so the first lookup is done correctly.

Fixes: 524c53981365 ("LU-16847 ldiskfs: ->fiemap replaced with ldiskfs_map_blocks.")
