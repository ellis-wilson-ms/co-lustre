LU-20107 tests: check the reserved/weight split in 77vg

The floor phase of sanityn/test_77vg checks only a lower bound. The
check passes when a reserved dispatch moves the virtual time. It also
passes when the select skips the reserved tree.

The floor phase now checks resvd_dispatch and weight_dispatch of each
rule against the split 13/25/37, within 2 dispatches. The backlogs
change to 32/40/80 writes of 64 KiB, so the skip defect fails the
reserved check.

    co3, 3 of 3 runs         pass, split 13/25/37
    virtual time moved       fails the weight check
    reserved tree skipped    fails the reserved check
