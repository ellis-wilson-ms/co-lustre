--- Description ---
Lustre can be built natively on a number of Linux operating systems.

It is further possible to build the lustre server and/or client in a docker container. 

 

The aim of this LUDOC working item is the following (as discussed in the DWG meeting):

	Document how to set up docker (to have a safe copy)

	Documen how the lustre server and/or client can be build in docker

	Provide any docker files and/or script examples are required

 

The more this can be generalised, the better. 

 

Bonus question (may warrant a separate item: how to run lustre in a container.)
