--- Description ---
conf-sanity test_73e, test_88a and test_250 fail every time in interop testing against 2.17.0 servers (Test-Parameters serverversion=2.17), because they test server changes that landed after 2.17.0 and their version checks do not exclude 2.17.0:

	test_73e: "check client /mnt/lustre failed" after "Try to mount after MGS remount".  That part of the test was added with the server fix 089f438ba9a5 ("LU-19692 mgc: notify MGS about target NIDs after reconnect", v2_17_50-34), but the test only checks for MDS >= 2.16.57.

	test_88a: "test_88a returned 127", parsing the 2.17.0 tunefs.lustre output.  Added with 23b31c5db51a ("LU-20360 utils: fix tunefs.lustre dropping mountfsoptions", v2_17_54-97), with no version check.

	test_250: "lcfg_erase did not list erased parameters".  Added with f5e198dc687a ("LU-18951 utils: lctl lcfg_erase erase fsname params", v2_17_51-23), but checks for MGS >= 2.16.54.86.

Seen in every custom serverversion=2.17 conf-sanity session for 64202, 68474 and 66529, e.g. https://testing.whamcloud.com/test_sessions/f8677e45-d2c9-48e2-9369-247f25ae08f5
