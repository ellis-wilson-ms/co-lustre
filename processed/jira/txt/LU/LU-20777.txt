--- Description ---
If any of the NIs listed in the imported lnet conf file is in "link down" state, lnetctl crashes (segfaults).

Steps to reproduce

lustre_rmmod
modprobe lnet
lnetctl lnet configure
lnetctl import lnet.conf

"lnetctl net add" doesn't appear to have this problem.
