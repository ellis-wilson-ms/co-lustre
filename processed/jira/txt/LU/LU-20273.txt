--- Description ---
static inline void orr_cpu_to_le(struct out_read_reply *orr_dst,
                 const struct out_read_reply *orr_src){
    orr_dst->orr_size = cpu_to_le32(orr_src->orr_size);
    orr_dst->orr_padding = cpu_to_le32(orr_src->orr_padding);
    orr_dst->orr_offset = cpu_to_le64(orr_dst->orr_offset); //cpu_to_le64(orr_src->orr_offset)
} 

Currently this is only called in-place (orr_cpu_to_le(orr, orr)), so no bug is triggered today. However, anyone refactoring or extending the code who calls these helpers with distinct src and dst pointers will get a silent misbehavior, as orr_offset will never be copied from the source.

Discovered by code inspect.
