--- Description ---
The patch replaces an indirect heuristic (vui_ra_valid flag)

with a direct check of the I/O type (CIT_FAULT),

which represents a page fault handling operation

(typically triggered by mmap'd page access).

CIT_FAULT explicitly indicates the I/O is happening

due to a page fault from a memory-mapped region,

rather than inferring from readahead validity.

as we can see, if vio->vui_ra_valid remains false, it won't trigger ll_io_read_page(). 

This means when in ll_io_read_page(), if the sign is true, it will no doubtly comes from a REAL read.

But if the sign is false, it will comes from Not only mmap, but also a normal write with page fault.

Regarding a write as a mmap won't affect this function's correctness, because ll_io_read_page() still will grab the page, 

but it may cause more RPCs as a mmap, miscalculate the statistic info and affect the RAS policy. 

So the change is more precise.
