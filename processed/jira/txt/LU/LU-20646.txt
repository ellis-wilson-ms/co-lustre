--- Description ---
Since patch “LU-12722 target: disable recovery for local clients” landed for 2.14, local clients are excluded by default from recovery (by not making them part of last_rcvd), unless the localrecov server mount option is specified. This avoid impacting or delaying recovery in case of crash of a Lustre server that was also running a Lustre client, because this client will never be able to reconnect.

But it looks like there are circumstances under which local clients are not excluded from recovery. For instance, if the client is mounted on the server before a Lustre target is re-located on this server, it appears the relocated target will still make the now local client be part of last_rcvd, hence not excluding it from recovery.
