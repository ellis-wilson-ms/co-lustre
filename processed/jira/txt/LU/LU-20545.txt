--- Description ---
In ll_iget_for_nfs(), when opening a special FID under .lustre, the code takes an inode reference via search_inode_for_lustre(), then looks up an existing dentry with d_lookup().

If the dentry is already cached, the reference from search_inode_for_lustre() should be dropped, otherwise, each hit of this path leaks one inode ref until the client is unmounted or the inode is forced out some other way.
