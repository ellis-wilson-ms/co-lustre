--- Description ---
We might be able to use LLVM's automatic reference counting to find ref count bugs in our kernel code. While this feature was originally designed for Objective-C, the annotations work fine on C. I was able to discover a few small bugs with this. This warrants more discussion with the upstream Linux/LLVM maintainers to understand if there is a path to adoption in the Linux kernel.

In the meantime, this ticket will track those bug fixes along with the PoC implementation.

[1] https://clang.llvm.org/docs/AutomaticReferenceCounting.html
