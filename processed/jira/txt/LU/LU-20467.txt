--- Description ---
We should have a Jenkins job that builds Lustre with Clang against the latest mainline kernel.

 

First, we should grab the latest kernel from https://www.kernel.org/ (in this case, 7.1). The version should be determined from a file in the build tree (perhaps a top-level META file or in one of the contrib/lbuild/ scripts).

 

Second, we should install the latest and greatest Clang compiler onto the build host (https://clang.llvm.org/). Clang 22 is the latest stable release, but 23 is preferred - if possible.

 

We should use `make LLVM=1 modules_prepare` on the kernel git tree allow Lustre to be built against this kernel without have to compile a completely new kernel.

 

Finally, we should use `./autogen.sh && ./configure LLVM=1 --with-linux=/path/to/linux --with-linux-objs=/path/to/linux/objs && make` to build Lustre against this new Clang-built kernel.
