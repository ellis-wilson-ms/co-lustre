--- Description ---
An update that solves one vulnerability can now be installed.

The SUSE Linux Enterprise 15 SP7 kernel was updated to 6.4.0-150700.53.45.1 to fix the following issue:

	CVE-2026-43284: xfrm: esp: avoid in-place decrypt on shared skb frags

    (bsc#1264449).

https://lists.suse.com/pipermail/sle-security-updates/2026-May/026008.html

The SUSE Linux Enterprise 15 SP7 kernel was updated to 6.4.0-150700.53.52.1 to fix various security

issues.

The following security issues were fixed:

	CVE-2025-54518: x86/CPU/AMD: Prevent improper isolation of shared resources

    in Zen2's op cache (bsc#1264013).

	CVE-2026-46300: net: skbuff: propagate shared-frag marker through

    pskb_copy() (bsc#1265209).

	CVE-2026-46333: ptrace: Logic bug in the Linux kernel's

    __ptrace_may_access() function (bsc#1265308).

https://lists.suse.com/pipermail/sle-security-updates/2026-May/026140.html
