--- Description ---
Discovered during work on LU-20534

mdd_lmm_dom_size()  only accepted  LOV_MAGIC_COMP_V1 . Files with a DoM component plus an extension component use  LOV_MAGIC_SEL  (same composite layout blob).

Those files were treated as non-DoM, so:

mdd_attr_set  did not drop  LA_SIZE  (LU-10509-style workaround).

mdd_swap_layouts  missed DoM size checks (e.g. plain swap allowed where migration rules should apply; wrong  mdd_dom_fixup()  when migrating between DoM layouts).
