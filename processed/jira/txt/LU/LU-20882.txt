--- Description ---
Two small problems in contrib scripts, both seen on Ubuntu hosts:

1. contrib/scripts/checkpatch-man.pl looks up the release that added a man page's subject with a git log/awk pipeline run through Perl backticks, i.e. /bin/sh. The pipeline uses a bash here-string (  Doing long search for AVAILABILITY version: git log -S ''

  sh: 1: Syntax error: redirection unexpected

and checkpatch reports "no git commit hash found", so the AVAILABILITY suggestion never works there.

2. contrib/git-hooks/commit-msg --help creates its temporary message file with mktemp "$ORIGINAL.XXXXXX" even though there is no message file, so it leaves a stray file in the current directory and never removes it: a hidden .XXXXXX file with GNU coreutils, a visible untracked XXXXXX file with uutils coreutils (Ubuntu 26.04's default). --help also prints "basename: missing operand".
