--- Comment (JIRAUSER19503, Fri, 5 Jun 2026 06:05:47 +0000) ---
HARD failure mode can currently be used in local mode.

My understanding is that HARD mode is intended to simulate an actual power failure (via powerman --off). In local mode, the test framework is running on the same node that would be powered off, which makes it difficult to recover the node and continue collecting test results.

Would it make sense to explicitly disallow HARD failure mode in local mode, or is there a scenario where this configuration is expected to work correctly?
