--- Description ---
Janitor highlighted that current batch of landings today brought in a memory leak in sanity2 that I saw in master next but forgot to isolate.

[18905.194295] LustreError: 273067:0:(class_obd.c:985:obdclass_exit()) obd_memory max: 316230095, leaked: 476 

The leak happens with both ldiskfs and zfs and no matter if dne is configured or not, so seems to be something generic.

this is due to:

static int mdd_pin_init(const struct lu_env *env, struct mdd_object *pobj,
			struct lu_buf *pin_buf)
...
	lu_buf_alloc(pin_buf, buf_size);
	pin_buf->lb_len = rc;

then in lu_buf_init() we pass lb_len to OBD_FREE():

void lu_buf_free(struct lu_buf *buf)
{
	LASSERT(buf);
	if (buf->lb_buf) {
		LASSERT(buf->lb_len > 0);
		OBD_FREE_LARGE(buf->lb_buf, buf->lb_len);

this is where math around obd_memory breaks.

introduced in commit:
