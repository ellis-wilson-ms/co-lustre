--- Description ---
The DKMS configuration checks for "--enable-gss" in the configure

options using the regex '--enable-gss[^-]'. This requires a character

after "gss", so it fails to match when "--enable-gss" is the last

argument in the options string, and ptlrpc_gss is silently omitted

from the DKMS module list.

 

Change the regex to '--enable-gss($|[^-])' so that it matches at end

of string as well, while still excluding longer options such as

"--enable-gss-keyring" or "-enable-gss-foo".

 

Apply the fix to both debian/dkms.conf.in and

lustre/scripts/dkms.mkconf.
