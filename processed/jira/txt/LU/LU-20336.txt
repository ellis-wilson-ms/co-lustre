--- Description ---
During simple workloads (like kernel compilation), I often see:

    LustreError: 1711:0:(osd_io.c:1005:osd_grow_blocksize()) \

      object [0x280000400:0xf2cf00:0x0]: change block \

      size4096 -> 131072 error rc = -95

dnode_set_blksz() returns EOPNOTSUPP on Linux when it finds that blocks beyond the first block are allocated or dirty. This error appears to be benign, but noisy.
