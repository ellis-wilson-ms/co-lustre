--- Description ---
The QP/CQ cleanup helper frees the queue pair array and the manager

queue pair but leaves the stored pointers dangling. On a device

initialization failure the cleanup runs once during the creation

helper's own error handling and then a second time from the device

teardown path, which only checks the pointers for NULL. The dangling

pointers pass that check, so the second pass iterates already freed

memory and frees it again, causing a use-after-free and double free.

In addition, the completion queue create error path returns the is-error predicate

instead of the actual negative error code.
