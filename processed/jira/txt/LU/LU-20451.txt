--- Description ---
When the setstripe restriction added by LU-17628 is enabled (llite.*.enable_setstripe_gid ≠ -1), running lfs setstripe against an existing file as a non-privileged, non-permitted user silently deletes the file and its data, replacing it with an empty file of the default layout.

 

Reproduction

# As admin, enable the restriction (the feature's intended config):
lctl set_param llite.*.enable_setstripe_gid=0

# As a normal (non-CAP_SYS_RESOURCE, non-permitted-gid) user:
echo "important data" > /mnt/lustre/f
lfs setstripe -c 1 /mnt/lustre/f      # prints a warning, exits 0
cat /mnt/lustre/f                      # EMPTY — original data is gone
stat -c %i /mnt/lustre/f               # inode changed (file was deleted+recreated)
