--- Description ---
On a ZFS OST, tunefs.lustre unconditionally appends "autodegrade=on" to the target parameters. As a result it silently discards an autodegrade value given on the command line.

 

1. Calling mkfs.lustre sets autodegrade to on by default

# truncate -s 2G /tmp/ost1.img
# zpool create -f -o cachefile=none lustre-ost1 /tmp/ost1.img
# mkfs.lustre --ost --backfstype=zfs --fsname=lustre --index=0 --mgsnode=xxx.xx.xx.xx@tcp lustre-ost1/ost1   Permanent disk data:
Device:     lustre-ost1/ost1
Target:     lustre:OST0000
Index:      0
Lustre FS:  lustre
Mount type: zfs
Flags:      0x62
              (OST first_time update )
Persistent mount opts:
Parameters: mgsnode=xxx.xx.xx.xx@tcp autodegrade=on
checking for existing Lustre data: not found
mkfs_cmd = zfs create -o canmount=off  lustre-ost1/ost1
  xattr=sa
  dnodesize=auto
  recordsize=1M
  compression=off
Writing lustre-ost1/ost1 properties
  lustre:mgsnode=xxx.xx.xx.xx@tcp
  lustre:autodegrade=on
  lustre:version=1
  lustre:flags=98
  lustre:index=0
  lustre:fsname=lustre
  lustre:svname=lustre:OST0000
# zfs get -H -o value lustre:autodegrade lustre-ost1/ost1
on
