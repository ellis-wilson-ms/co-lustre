2026-07-06T08:33:29.164327-07:00 ddn1oss4 kernel: LustreError: 4036970:0:(osp_sync.c:717:osp_sync_interpret()) reply req 00000000c36f804e/1, rc -22, transno 0
2026-07-06T08:33:29.168328-07:00 ddn1oss4 kernel: LustreError: 4036966:0:(osp_sync.c:717:osp_sync_interpret()) reply req 000000008bf65def/1, rc -22, transno 0

this is a result of the race where lfs mirror resync is interrupted by a regular write to a file.

osp_sync_interpret() handling is rather bad at the moment:

	-EINVAL is treated as a transient error

	OSP tries to reschedule it after timeout as long as object still exists

	this may block subsequent update to the object

	update has no chance as layout version can't decrease

instead we should drop it upon first EINVAL
