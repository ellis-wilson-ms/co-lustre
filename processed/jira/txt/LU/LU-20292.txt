--- Description ---
It looks like Lustre kernel rpms naming could be improved to better reflect the baseline kernel version, e.g.

baseline kernel-4.18.0-553.117.1.el8_10.src.rpm Lustre kernel-4.18.0-553.117.1.el8_lustre.x86_64.rpm

-> should be kernel-4.18.0-553.117.1.el8_10_lustre.x86_64.rpm

baseline kernel-5.14.0-503.40.1.el9_5.src.rpm Lustre kernel-5.14.0-503.40.1_lustre.el9.x86_64.rpm

-> should be kernel-5.14.0-503.40.1.el9_5_lustre.x86_64.rpm

baseline kernel-6.12.0-124.49.1.el10_1.src.rpm Lustre kernel-6.12.0-124.49.1_lustre.el10.x86_64.rpm

-> should be kernel-6.12.0-124.49.1.el10_1_lustre.x86_64.rpm

This is important for tools that check the kernel version and make string version comparisons ("is the kernel version at least xxx?").
