--- Description ---
Summary

Add struct ll_ioc_io_scope and LL_IOC_SET_IO_SCOPE / LL_IOC_CLEAR_IO_SCOPE on master. Define all four scopes; implement FILE / MIRROR; STRIPE and OBJECT return -EOPNOTSUPP at the ioctl and are not stored.

Description

Freeze the UAPI in the first patch (field layout, not every scope's semantics). This replaces the FLR designated-mirror ioctl as the extensible target-selection interface. LL_IOC_FLR_SET_MIRROR stays as an alias for {MIRROR, mirror_id}.

ios_comp_id stays in the struct for STRIPE / OBJECT (opened in P1b / P2). P1 FILE / MIRROR require it to be 0. ios_stripe_idx is documented as relative among objects sharing this file offset (opened in P1b). ios_fid is OBJECT's sole identity (opened in P2).

Unknown scope, non-zero flags / padding, or unused identity fields → EINVAL. NonFILE scopes require O_DIRECT. No lov / cl_object changes: ll_io_set_scope() only ever sees FILE / MIRROR.

Userspace: llapi_io_scope_set/clear. llapi_mirror_set/clear keep their signatures and still issue SET_MIRROR.

Prefer landing in the same Gerrit topic as LU-20534 or the EC series.

Acceptance

	Existing non-EC lfs mirror resync/verify behaviour is unchanged.

	SET_MIRROR alias still works (llapi_mirror_set / lfs mirror resync).

	STRIPE / OBJECT → -EOPNOTSUPP; not stored on the fd.

	Non-zero padding / flags / unused identity fields / unknown scope / non-O_DIRECT MIRROR → -EINVAL.

	No lov / cl_object.h changes.
