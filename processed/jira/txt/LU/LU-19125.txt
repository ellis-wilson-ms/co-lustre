It's worthwhile to note that it is possible to implement parallel scanning on a single directory by splitting up the 2^63 directory hash cookie into N (or 2N or similar) ranges and then have each thread call telldir() to their relative offset and then call readdir() until the returned entry hash hits the start of the next window..
