--- Environment ---
DKMS with DOCA >= 3.2.0

--- Description ---
Since DOCA 3.2.0, the EL packages ship the OFED kernel modules as the DKMS module mlnx-ofa_kernel (mlnx-ofa_kernel-dkms RPM) instead of kmod RPMs. dkms.mkconf adds only the Debian name mlnx-ofed-kernel to BUILD_DEPENDS (LU-19553), so on a kernel update DKMS may build Lustre before the OFED modules for that kernel.
