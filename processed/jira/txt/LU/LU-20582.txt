--- Description ---
FNAME pattern detection is supposed to check the following:

	if the name end with number

	if the numbers are consecutive between each stat process

	if the match count > lli_sa_match_count (statahead_fname_match_hit parameter)

All of this are ignored if the directory is accessed by multiple processes running stats with names ended by a number:

Reproducer:

[root@client-el8 lustre]# seq 1 10 1000 | xargs -P 100 -I{} stat testdir/testfile{} > /dev/null;
pgrep ll_sa

Each stat process is accessing to only one entry making statahead inefficient. And each statahead process will timeout after 30s for a stat during several ms.
