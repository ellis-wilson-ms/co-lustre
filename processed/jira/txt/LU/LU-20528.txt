--- Description ---
1) lfs quota long options wrongly consume an extra argument

For example, `lfs quota --all -u` cannot show the quota info for all users:

# lfs quota -a -u /mnt/lustre
Disk usr quotas
     Filesystem  quota_id  kbytes  bquota  blimit  bgrace   files  iquota  ilimit  igrace 
    /mnt/lustre quota_usr       0       0       0       -       0       0       0       - 
    /mnt/lustre quota_2usr       0       0       0       -       0       0       0       - 

# lfs quota --all -u /mnt/lustre
lfs quota: no quota type to iterate
Display disk usage and limits.
usage: quota [-q] [-v] [-h] [-o OBD_UUID|-o OST_IDX|-m MDT_IDX]
             [{-u|-g|-p} UNAME|UID|GNAME|GID|PROJID]

             [--inode-hardlimit|--ihardlimit]
             [--inode-grace|--igrace|--itime]

             [MOUNT_POINT ...]
       quota -t {-u|-g|-p} [--pool OST_POOL_NAME] [MOUNT_POINT ...]
       quota [-hqv] {-U|-G|-P} [--pool OST_POOL_NAME] [MOUNT_POINT ...]
       quota -a {-u|-g|-p} [-n] [-s START_QID] [-e END_QID]
             [--show-root] [MOUNT_POINT ...]
